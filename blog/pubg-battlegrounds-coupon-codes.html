PUBG: 배틀그라운드 쿠폰 코드 등록 방법과 '특별 보급' 구별법

겜대·ECM 쿠폰 운영자·2026.10.04 작성

PUBG: 배틀그라운드(PC·PS5)의 쿠폰(교환 코드)은 게임 안이 아니라 공식 코드 등록 페이지에서 KRAFTON ID로 로그인해 입력합니다. 2026년 10월 4일 기준으로 ECM 쿠폰이 확인한 활성 코드는 없는 상태이며, 최신 코드는 PUBG: 배틀그라운드 쿠폰 페이지에서 확인 시각과 함께 갱신됩니다. 이 글에서는 코드 등록 방법과, 자주 혼동하는 '특별 보급'의 뜻, 코드가 안 먹힐 때 점검할 점을 정리했습니다.

PUBG: 배틀그라운드란

PUBG: 배틀그라운드는 크래프톤이 서비스하는 배틀로얄 FPS로, PC와 PlayStation 5에서 즐길 수 있습니다. 같은 이름의 모바일판(펍지 모바일)과는 별도 클라이언트·계정 체계를 쓰기 때문에, 코드 등록 페이지와 보상도 서로 섞이지 않습니다. 검색할 때 '배틀그라운드'와 '펍지 모바일'을 구분해야 원하는 코드 등록 페이지로 바로 갈 수 있습니다.

쿠폰 코드 등록 방법

PUBG: 배틀그라운드의 코드는 게임 내 메뉴가 아니라 웹 등록 페이지에서 처리합니다.

  1. 공식 코드 등록 페이지(pubg.com/ko/events/redeem)로 들어갑니다.
  2. KRAFTON ID로 로그인합니다. 게임을 실행할 때 쓰는 계정과 같습니다.
  3. 코드를 입력하고 등록을 누르면, 보상은 보통 게임 안 보관함으로 지급됩니다.

코드는 대소문자를 구분하는 영문·숫자 조합이 많습니다. 손으로 옮겨 적다가 0과 O, 1과 I를 헷갈리는 경우가 흔해서, 가능하면 복사·붙여넣기를 권합니다.

'특별 보급'은 코드와 다릅니다

배틀로얄 장르에서 '특별 보급(공중보급)'은 경기 중 맵 위에 떨어지는 상자로, 일반 보급보다 강한 무기·장비가 들어 있는 인게임 요소를 가리킵니다. 이건 코드로 받는 보상이 아니라 매 경기마다 등장하는 기본 게임 규칙입니다. '쿠폰 코드'와 '특별 보급'을 같은 것으로 검색하는 경우가 많은데, 특별 보급 상자를 빨리 얻는 방법이 궁금하다면 낙하산을 보급 신호탄 근처로 유도해 먼저 도착하는 것이 핵심이고, 코드로 받는 보상(스킨·아이템 꾸러미 등)을 찾는다면 아래 코드 등록 페이지를 확인하면 됩니다.

코드는 언제, 어디서 나오나

정해진 발행 주기는 없고, 공식 홈페이지 공지·공식 SNS·콜라보 이벤트, 또는 대회·방송 연계 프로모션에서 코드가 풀리는 경우가 많습니다. 커뮤니티에 떠도는 코드는 만료됐거나 다른 지역 서버용이 섞여 있을 수 있으니, 등록일이 표시된 출처에서 다시 확인하는 편이 안전합니다. ECM 쿠폰이 확인한 코드는 확인 즉시 PUBG: 배틀그라운드 쿠폰 페이지에 올라가니, 즐겨찾기해 두면 놓치지 않을 수 있습니다.

코드가 안 먹힐 때 확인할 점

  • 코드는 보통 계정당 한 번만 쓸 수 있습니다. 이미 쓴 코드는 다시 등록해도 받지 못합니다.
  • 코드 앞뒤에 공백이 섞이지 않았는지, 숫자 0과 영문 O를 혼동하지 않았는지 확인하세요.
  • 등록 페이지 로그인 계정이 실제 게임을 플레이하는 KRAFTON ID와 같은지 다시 확인하세요.
  • 지역·기간 한정 코드는 등록 기간이 지나면 더 이상 입력되지 않습니다.

출처가 불분명한 곳에서 "미공개 코드"를 안다며 계정 정보나 로그인 비밀번호를 요구한다면 응하지 않는 게 안전합니다. 이런 수법은 게임 쿠폰 사기 구별법에서 다룬 전형적인 패턴과 같습니다. 여러 게임의 코드를 한 번에 관리하는 요령은 게임 쿠폰 완벽 가이드에서도 확인할 수 있습니다.

'특별 보급'도 코드로 받나요?

아닙니다. 특별 보급(공중보급)은 매 경기마다 맵에 떨어지는 인게임 상자로, 코드와는 별개의 기본 게임 규칙입니다. 코드로 받는 보상은 등록 페이지에서 입력해야 받을 수 있습니다.

지금 쓸 수 있는 코드가 있나요?

2026년 10월 4일 기준으로 ECM 쿠폰이 확인한 활성 코드는 없습니다. 최신 상태는 PUBG: 배틀그라운드 쿠폰 페이지에서 확인 시각과 함께 갱신됩니다.

PUBG: 배틀그라운드는 코드 발행이 잦은 편은 아니지만, 등록 페이지 위치와 KRAFTON ID 로그인이라는 기본 절차만 알아두면 코드가 나왔을 때 바로 챙길 수 있습니다. '특별 보급'처럼 이름이 비슷한 게임 내 요소와 혼동하지 않도록 구분해 두고, 확인된 코드 목록은 즐겨찾기해 그때그때 챙기는 편이 가장 확실합니다.
