포켓몬 GO 코드 입력법과 지금 받을 수 있는 보상 정리

겜대·ECM 쿠폰 운영자·2026.10.09 작성

포켓몬 GO 쿠폰 코드는 게임 안이 아니라 공식 Pokémon GO Web Store에서 계정으로 로그인한 뒤 입력합니다. 2024년 2월부터 안드로이드 앱 내 코드 입력이 막히면서 생긴 변화로, 지금은 플랫폼과 관계없이 모두 웹에서 등록합니다. ECM 쿠폰이 2026.10.09 기준으로 확인한 코드는 포켓몬 GO 쿠폰 페이지에서 바로 볼 수 있고, 이 글에서는 코드 종류 구분부터 입력 방법, 안 먹힐 때 체크리스트까지 정리합니다.

포켓몬 GO 쿠폰, 왜 웹에서만 입력할까

원래 포켓몬 GO는 안드로이드에서는 앱 안의 상점 화면에서, iOS에서는 웹에서 코드를 넣는 방식이 서로 달랐습니다. 하지만 Pokémon GO 공식 공지에 따르면 2024년 2월 13일부터 안드로이드 앱 내 코드 입력 기능이 막히고, 이후로는 플랫폼에 상관없이 모두 Pokémon GO Web Store에서 게임과 같은 계정으로 로그인해 코드를 입력하는 방식으로 통합됐습니다. 코드 입력 메뉴를 앱 안에서 찾다가 못 찾는 경우가 많은데, 애초에 앱에는 그 메뉴가 없다고 보면 됩니다.

다만 Niantic 공식 도움말은 어린이 계정(차일드 어카운트)은 보호자 동의 구조상 Web Store 자체를 이용할 수 없다고 안내합니다. 자녀 계정으로 코드를 등록하려 한다면 이 제한부터 확인해야 합니다.

선물 코드와 프로모션 코드는 다릅니다

포켓몬 GO 코드는 크게 두 종류입니다. 하나는 콜라보·이벤트 기념으로 무료로 풀리는 '선물 코드'이고, 다른 하나는 상품을 구매할 때 영수증이나 패키지에 동봉돼 오는 '프로모션 코드'입니다. 선물 코드는 누구나 입력할 수 있지만, 프로모션 코드는 계정당 혹은 한 달에 한 번처럼 사용 횟수가 제한된 경우가 있어 아무 코드나 여러 번 넣을 수 있는 것은 아닙니다. 지금 ECM 쿠폰이 확인한 코드가 선물형인지 프로모션형인지도 쿠폰 페이지의 보상 설명에서 함께 확인할 수 있습니다.

코드 입력 방법

  1. 브라우저로 공식 Pokémon GO Web Store 코드 입력 페이지에 접속합니다.
  2. 게임에서 쓰는 계정(구글·애플·페이스북·Niantic 계정 등)으로 로그인합니다.
  3. 코드 입력란에 알파벳과 숫자를 대소문자 그대로 붙여 넣습니다.
  4. 제출을 누르면 보상이 우편함이 아니라 게임 내 가방(소지품)으로 바로 들어갑니다.

앱을 지웠다 다시 설치해도 코드와는 상관이 없습니다. 코드는 계정에 귀속되기 때문에, 로그인한 계정이 게임에서 쓰는 계정과 같은지만 맞으면 됩니다.

지금 받을 수 있는 보상 종류

ECM 쿠폰이 확인한 포켓몬 GO 코드는 두 가지 방향으로 나뉩니다. 하나는 베리류(라즈베리·파인애플베리·나나베리)와 포켓볼을 한 번에 챙겨주는 소모품 묶음형이고, 다른 하나는 브랜드 콜라보 기념으로 나온 아바타 의상 같은 꾸미기 아이템입니다. 소모품형은 사용 기한이 따로 정해지지 않은 경우가 많고, 콜라보 아이템은 콜라보 종료 시점에 맞춰 입력 마감일이 정해지는 편입니다. 정확한 보상 구성과 마감일은 코드마다 다르므로 포켓몬 GO 쿠폰 페이지에서 최신 상태를 확인하는 것이 가장 정확합니다.

코드가 안 먹힐 때 체크리스트

  • 대소문자를 구분해 정확히 입력했는지 다시 확인하세요. 알아보기 어려운 대문자 I와 소문자 l, 숫자 0과 알파벳 O가 코드에 섞여 있을 수 있습니다.
  • 로그인한 계정이 실제로 게임을 플레이하는 계정인지 확인하세요. 여러 개의 구글·애플 계정을 쓰는 경우 다른 계정으로 로그인해 등록이 안 되는 일이 흔합니다.
  • 프로모션 코드라면 이미 이번 달 사용 횟수를 다 썼을 수 있습니다.
  • 위 방법으로도 안 되면 코드 자체가 만료됐을 가능성이 큽니다. 쿠폰 코드가 안 먹힐 때 공통으로 확인하는 점은 쿠폰 코드 안 될 때 확인할 5가지에서도 다룹니다.

자주 묻는 질문

포켓몬 GO 쿠폰은 앱에서도 입력할 수 있나요?

아닙니다. 2024년 2월 13일부터 안드로이드 앱 내 입력 기능이 막혀, 지금은 플랫폼과 관계없이 공식 Pokémon GO Web Store에서만 입력합니다.

어린이 계정으로도 코드를 등록할 수 있나요?

Niantic 공식 안내에 따르면 어린이(차일드) 계정은 Web Store 자체를 이용할 수 없어 코드 등록이 되지 않습니다. 보호자 계정으로 등록해야 합니다.

같은 코드를 여러 번 입력해도 되나요?

선물 코드는 보통 한 번만 유효하고, 프로모션 코드는 계정당 또는 월 1회처럼 횟수 제한이 있는 경우가 있습니다. 같은 코드를 반복해서 넣어도 추가 보상은 받을 수 없습니다.

포켓몬 GO 코드는 게임 안이 아니라 웹 스토어에서 계정으로 로그인해 넣는다는 것만 기억하면 헷갈릴 일이 적습니다. 코드 구성은 콜라보·이벤트에 맞춰 수시로 바뀌므로, 지금 쓸 수 있는 코드와 정확한 보상·마감일은 게임 쿠폰 완벽 가이드와 함께 포켓몬 GO 쿠폰 페이지에서 그때그때 확인하는 것이 가장 확실합니다.
