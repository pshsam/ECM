킹샷 쿠폰 코드 등록 방법 두 가지와 안 먹힐 때 체크리스트

겜대·ECM 쿠폰 운영자·2026.10.03 작성

킹샷(Kingshot) 쿠폰 코드는 등록 방법이 두 가지입니다. 게임 밖 웹 페이지인 기프트 코드 센터에서 넣는 방법과, 앱을 켠 채로 프로필 > 설정 > Gift Code 메뉴에서 바로 넣는 방법입니다. 같은 센추리게임즈(Century Games) 작품인 화이트아웃 서바이벌이 웹 페이지로만 등록받는 것과 다른 점입니다. 지금 쓸 수 있는 코드는 킹샷 쿠폰 페이지에서 확인할 수 있고, 이 글에서는 두 가지 등록 방법과 코드가 안 먹힐 때 점검할 부분을 정리합니다.

킹샷 기프트 코드란

킹샷은 센추리게임즈가 서비스하는 모바일 생존·전략(SLG) 게임으로, 영지를 키우고 동맹과 함께 전투를 치르는 구조가 중심입니다. 게임사는 업데이트나 기념일에 맞춰 다이아몬드·스킬북·가속 아이템 같은 보상을 주는 기프트 코드를 공개하는데, 정해진 발급 주기는 없고 공식 채널 공지를 따라 그때그때 풀립니다.

등록 방법 두 가지

두 방법 모두 결과는 같지만, 상황에 따라 편한 쪽을 고르면 됩니다.

① 웹 기프트 코드 센터

  1. 게임을 실행해 화면 왼쪽 위 아바타를 눌러 플레이어 ID를 확인하고 복사합니다.
  2. 브라우저로 공식 기프트 코드 센터에 접속해 플레이어 ID로 로그인합니다.
  3. 코드를 붙여 넣고 등록을 누르면 보상이 게임 내 우편함으로 지급됩니다.

② 인게임 프로필 메뉴

  1. 게임 안에서 프로필 아이콘을 누른 뒤 설정(톱니바퀴)으로 들어갑니다.
  2. 설정 목록에서 Gift Code(기프트 코드) 항목을 찾아 누릅니다.
  3. 입력창에 코드를 넣고 확인을 누르면 바로 우편함에 보상이 들어옵니다.

기기를 바꾸거나 PC 연동 플레이 중이라도 같은 계정이면 두 경로 중 편한 쪽으로 등록할 수 있습니다. 다만 코드마다 유효기간이 다르므로, 등록 전 화면에 뜨는 안내 문구로 기간을 한 번 더 확인하는 편이 안전합니다.

코드로 받을 수 있는 보상 종류

킹샷 기프트 코드는 보통 성장에 바로 쓸 수 있는 재화 위주로 지급됩니다. 다이아몬드(유료 재화), 영웅 경험치, 장군 가속 아이템, 신화 등급 스킬북·교본, 골드열쇠 같은 자원이 코드별로 조합돼 나옵니다. 가끔 기념일 코드에는 며칠짜리 아바타 프레임 같은 장식 보상이 함께 붙기도 합니다. 코드별로 구성이 달라 어떤 코드가 가장 먼저 쓸 가치가 있는지는 바뀌므로, 정확한 구성은 등록 전 화면의 미리보기나 킹샷 쿠폰 페이지에서 확인하는 것이 가장 정확합니다.

코드가 풀리는 경로와 미리 챙기는 법

킹샷 코드는 공식 디스코드·X(트위터)·페이스북 공지, 그리고 대규모 업데이트나 서비스 기념일 이벤트 때 함께 풀리는 경우가 많습니다. 커뮤니티에 떠도는 코드 중에는 이미 만료됐거나 다른 게임(화이트아웃 서바이벌 등) 코드와 혼동된 것이 섞여 있을 수 있으니, 날짜가 명시된 공식 공지나 검증된 정리 페이지에서 다시 확인하는 편이 안전합니다.

코드가 안 먹힐 때 확인할 점

  • 대소문자와 앞뒤 공백을 확인하세요. 영문·숫자가 섞인 코드는 옮겨 적을 때 오탈자가 나기 쉽습니다.
  • 코드는 계정당 한 번만 쓸 수 있습니다. 이미 등록한 코드를 다시 넣으면 오류가 뜹니다.
  • 웹 센터를 쓸 때는 플레이어 ID가 정확한지 다시 확인하세요. ID를 잘못 넣으면 다른 계정으로 등록될 수 있습니다.
  • 두 방법 다 정확히 입력했는데 안 된다면 유효기간이 지났을 가능성이 큽니다. 서버·지역에 따라 적용 여부가 다를 수도 있습니다.

자주 묻는 질문

킹샷 코드는 어디서 입력하나요?

웹 기프트 코드 센터에서 플레이어 ID로 로그인해 넣는 방법과, 게임 안 프로필 > 설정 > Gift Code 메뉴에서 바로 넣는 방법이 있습니다. 둘 다 같은 결과입니다.

인게임 메뉴로 등록했는데 웹에서도 또 등록해야 하나요?

아니요. 한쪽에서 등록에 성공하면 같은 계정의 우편함에 보상이 들어가므로 다시 등록할 필요가 없습니다.

화이트아웃 서바이벌 코드를 킹샷에 써도 되나요?

안 됩니다. 두 게임 모두 센추리게임즈가 서비스하지만 코드는 게임별로 따로 발급돼 서로 호환되지 않습니다. 화이트아웃 서바이벌 쪽 등록 방법은 화이트아웃 서바이벌 기프트 코드 글에서 따로 정리했습니다.

킹샷은 웹 센터와 인게임 메뉴 두 가지로 코드를 받을 수 있어 화이트아웃 서바이벌보다 등록 절차가 한 단계 덜 번거롭습니다. 계정당 한 번이라는 기본 규칙만 기억해 두면 등록 자체는 쉬우니, 최신 코드는 공식 채널이나 검증된 정리 페이지에서 그때그때 확인하는 것이 가장 확실합니다.
