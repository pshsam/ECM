블록스 프루트 코드 쓰는 법: 입력 위치부터 보상 종류까지

겜대·ECM 쿠폰 운영자·2026.09.23 작성·2026.09.24 수정

블록스 프루트(Blox Fruits) 코드는 게임 화면 왼쪽의 X(트위터) 모양 버튼을 눌러 입력합니다. 보상은 대부분 경험치(EXP) 2배 부스트나 스탯 초기화(리셋)이고, 가끔 인게임 화폐나 칭호가 함께 나옵니다. 코드는 개발사가 예고 없이 닫아버리기 때문에, 지금 살아있는 코드 목록은 이 글이 아니라 별도로 갱신되는 페이지에서 확인하는 게 안전합니다. 여기서는 코드를 입력하는 순서, 보상 종류, 코드가 안 먹힐 때 점검할 것들을 정리했습니다.

블록스 프루트 코드란

블록스 프루트는 로블록스 안에서 서비스되는 원피스풍 액션 RPG로, 개발사 Gamer Robot Inc.가 업데이트나 팔로워·좋아요 목표 달성, 서버 오류에 대한 보상 등의 이유로 코드를 공개합니다. 로블록스는 게임마다 코드 입력 위치가 제각각인데, 블록스 프루트는 화면 왼쪽의 X 아이콘 버튼이 입력 창으로 이어지는 구조입니다. 다른 로블록스 게임에서 코드를 넣던 방식을 그대로 적용하면 위치를 못 찾는 경우가 많으니 구분해서 알아두는 게 좋습니다.

코드 입력하는 방법

순서 자체는 간단하지만, 대소문자를 하나라도 틀리면 실패로 처리되니 복사·붙여넣기로 진행하는 걸 권합니다.

  1. 지금 사용 가능한 코드를 확인합니다. 코드는 블록스 프루트 쿠폰 페이지에서 하루 두 번 갱신됩니다.
  2. 게임을 실행하고 화면 왼쪽의 X(트위터) 모양 버튼을 누릅니다.
  3. 코드 입력 칸에 붙여넣고 확인을 누릅니다.
  4. 보상은 즉시 지급되거나 게임 내 알림으로 도착합니다.

코드로 받을 수 있는 보상 종류

코드마다 주는 보상이 다르지만, 크게 네 가지로 나뉩니다. 어떤 코드가 어떤 보상을 주는지는 쿠폰 페이지의 표에서 확인할 수 있습니다.

보상 유형 설명
EXP 부스트 가장 흔한 보상. 일정 시간 동안 경험치를 2배로 얻습니다.
스탯 초기화 검술·총술·악마의 열매 등에 분배한 스탯 포인트를 다시 나눌 수 있게 리셋합니다.
인게임 화폐 소액의 게임 내 화폐를 지급합니다. 금액은 코드마다 다릅니다.
칭호 특정 문구가 적힌 인게임 타이틀을 얻습니다. 전투력에는 영향이 없습니다.

코드가 안 먹힐 때 확인할 점

  • 대소문자·띄어쓰기 — 로블록스 코드는 대소문자를 구분합니다. 손으로 옮겨 적지 말고 복사해서 붙여넣으세요.
  • 계정당 한 번 — 같은 코드는 한 계정에서 한 번만 됩니다. "이미 사용됨"이 뜨면 이전에 받은 겁니다.
  • 예고 없는 종료 — 개발팀은 코드를 공지 없이 닫습니다. 대소문자를 다 확인했는데도 안 되면 이미 닫힌 코드일 가능성이 큽니다.
  • 서버 문제 — 게임 서버가 불안정할 때는 정상 코드도 일시적으로 입력이 안 될 수 있어, 잠시 후 다시 시도해 보는 게 좋습니다.

새 코드는 언제 올라오나

정해진 발행 주기는 없습니다. 큰 업데이트가 나오거나, 개발팀 소셜 채널의 팔로워·좋아요 수가 목표치를 넘거나, 서버 오류로 플레이어들이 불편을 겪었을 때 보상 성격으로 코드가 풀리는 경우가 많습니다. 정확한 출시 시점은 개발팀 공식 채널에서 예고하므로, 새 코드를 놓치고 싶지 않다면 공식 채널을 직접 확인하는 게 가장 정확합니다. 코드가 뜬 것처럼 보여도 출처가 불분명한 유튜브 영상이나 커뮤니티 글에서 "무료 아이템"을 미끼로 개인정보나 계정 정보를 요구하는 경우가 있으니, 가짜 쿠폰 사이트 구별법을 참고해 구분하는 것이 안전합니다.

자주 묻는 질문

코드 입력 칸이 안 보여요.

화면 왼쪽 가장자리를 확인하세요. X(트위터) 모양의 작은 아이콘이 코드 입력 버튼입니다. 로딩이 덜 됐거나 UI가 가려진 경우 잠시 후 다시 확인하면 나타납니다.

모바일에서도 같은 방법인가요?

네, PC와 모바일 모두 같은 X 아이콘 버튼을 눌러 코드를 입력합니다. 화면 크기가 작아 아이콘이 잘 안 보일 수 있으니 화면을 확대해 위치를 확인하세요.

다른 로블록스 게임도 코드 입력 위치가 같나요?

아니요, 게임마다 다릅니다. 게임 종류가 다양한 로블록스는 개발사별로 코드 입력 UI를 따로 만들기 때문에, 다른 게임을 할 때는 그 게임의 쿠폰 페이지에서 입력 위치를 다시 확인하는 게 안전합니다. 게임 장르별로 쿠폰을 어떻게 다루는지는 게임 쿠폰 완벽 가이드에서도 확인할 수 있습니다.

코드 자체는 입력 방법만 알면 어렵지 않지만, 살아있는 코드를 찾는 게 관건입니다. 개발팀이 예고 없이 코드를 닫기 때문에, 검증되지 않은 코드를 여기저기서 긁어모으기보다는 확인된 목록을 참고하는 편이 시간을 아낄 수 있습니다.
