보더랜드 SHiFT 코드 25개 기록: 30일 동안 딱 1개만 빠졌다

GamerDaddy·ECM 쿠폰 운영자·2026.10.21 작성

ECM 쿠폰은 9월 22일부터 10월 21일까지 30일 동안 보더랜드(SHiFT) 코드 25개를 새로 확인해 목록에 올렸어요. 10월 21일 기준으로 24개가 아직 목록에 있고, 목록에서 뺀 건 1개뿐이에요. 다른 게임은 같은 날 올라온 코드도 며칠 안에 절반 넘게 빠지는 경우가 있는데, 보더랜드는 거의 빠지지 않았어요. 이유는 코드 성격이 달라서예요 — 보상이 캐릭터·무기 스킨인 코드는 공식 만료일이 2030년 말로 잡혀 있어 사실상 상시나 다름없고, 골든키류는 만료일을 따로 공지하지 않은 채 쓸 수 있는 채로 남아 있어요.

아래 숫자는 ECM 쿠폰이 코드마다 남기는 기록(처음 확인한 날, 목록에서 제외한 날)을 직접 센 값이에요. 게임사가 발표한 발급일이 아니라는 점이 이 글을 읽는 핵심이라, 어떻게 셌고 이 기록으로 알 수 없는 것이 무엇인지부터 적어 둘게요.

어떻게 셌고, 무엇을 알 수 없나요

  • 기간: 2026년 9월 22일~10월 21일(30일). ECM 쿠폰이 보더랜드 코드를 처음 확인한 날부터 이 글을 쓴 날까지예요.
  • 최초 확인일: 게임사가 코드를 낸 날이 아니라, ECM 쿠폰이 공식 채널이나 서로 다른 출처 2곳에서 확인해 올린 날이에요(등록 기준).
  • 목록에서 제외한 날: ECM 쿠폰이 확인할 때 쓸 수 없다고 보고 목록에서 뺀 날이에요. 공식 만료일이 적힌 코드는 그 날짜가 지나면 제외했고, 만료일이 없는 코드는 재확인했을 때 안 되는 걸 본 날을 썼어요.
  • 아직 목록에 있는 코드: 관측이 끝나지 않은 코드예요. 표에 적은 기간은 "10/21까지 최소 이만큼 목록에 있었다"는 뜻이에요.

지금 쓸 수 있는 코드와 입력 방법

이 글을 쓴 10월 21일 기준으로 ECM 목록에 있는 보더랜드 코드는 24개예요. 코드와 보상은 수시로 바뀌니 이 글에는 적지 않았어요. 보더랜드 쿠폰 코드 페이지에서 지금 상태를 확인하세요. 입력은 SHiFT 웹사이트에 로그인해 Rewards 탭의 Code Redemption 칸에 코드를 넣고 Check를 누르면, 그 코드를 쓸 수 있는 게임과 플랫폼이 나와요. 거기서 내 게임·플랫폼을 고르면 등록되고, 보상은 게임 안에서 받아요(보더랜드 4는 메뉴의 Customization에서 확인). 코드는 SHiFT 계정당 한 번만 쓸 수 있고, 여러 게임에 쓸 수 있는 코드라도 게임마다 따로 등록해야 해요.

ECM 쿠폰이 추적하는 전체 게임을 같은 방식으로 센 기록은 게임 쿠폰 코드 115개 기록 분석에 있어요. 반대로 같은 날 올라온 코드도 며칠 안에 절반 넘게 빠진 사례는 애니메 뱅가드 코드 27일 기록에서 볼 수 있어요. 게임마다 코드가 목록에 남는 기간이 이렇게 다르니, 보더랜드도 다음 집계 때 다시 확인해 볼게요.
