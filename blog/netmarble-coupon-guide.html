넷마블 쿠폰 등록 방법: 킹스로드·어라이즈·SOL 실패 이유까지

겜대·ECM 쿠폰 운영자·2026.09.25 작성

넷마블 게임은 게임마다 쿠폰(교환 코드) 등록 방법이 조금씩 다릅니다. 왕좌의 게임: 킹스로드는 웹 등록 페이지에서만 코드를 넣고, 나 혼자만 레벨업: 어라이즈는 인게임 메뉴와 웹 페이지 둘 다 가능하며, SOL: 인챈트는 계정당 한 번만 등록됩니다. 이 차이를 모르고 다른 게임 방식대로 시도하면 코드가 안 들어가는 경우가 많습니다. 아래에서 게임별 등록 순서와 자주 실패하는 지점을 정리했습니다.

넷마블 쿠폰, 왜 게임마다 등록 방법이 다른가

넷마블은 게임마다 개발 스튜디오와 서버 구조가 달라, 쿠폰 등록도 하나의 통합 창구 대신 게임별 페이지를 운영합니다. 공통 주소인 coupon.netmarble.com 아래에 게임마다 별도 경로(예: /got, /sololv, /sol)가 붙는 구조입니다. 일부 게임은 여기에 더해 인게임 메뉴에서도 코드를 넣을 수 있어, 어떤 방법이 맞는지 헷갈리기 쉽습니다. 아래 세 게임을 기준으로 실제 등록 방법을 확인해보겠습니다.

왕좌의 게임: 킹스로드 쿠폰 등록 방법

킹스로드 쿠폰 코드 페이지에서 확인한 코드를 넷마블 공식 쿠폰 등록 페이지(coupon.netmarble.com/got)에서 넣습니다. 계정 로그인 후 코드를 입력하는 방식이며, 다른 넷마블 게임과 달리 PID(플레이어 아이디) 입력은 요구하지 않습니다. 로그인한 계정과 실제 플레이하는 계정이 같은지만 확인하면 됩니다.

  1. 게임 공식 공지나 코드 페이지에서 코드를 정확히 복사합니다.
  2. coupon.netmarble.com/got 에서 보상을 받을 계정으로 로그인합니다.
  3. 코드를 붙여넣고 등록한 뒤, 게임을 실행해 우편함에서 보상을 받습니다.

나 혼자만 레벨업: 어라이즈 쿠폰 등록 방법

나 혼자만 레벨업: 어라이즈 쿠폰 코드 페이지에서 코드를 확인했다면 두 가지 방법 중 편한 쪽을 고르면 됩니다. 게임 안에서는 설정 메뉴의 Redeem Code(코드 교환) 항목에서 바로 입력할 수 있고, 게임을 실행하지 않은 상태라면 넷마블 쿠폰 등록 페이지에서도 같은 코드를 넣을 수 있습니다. 두 경로 모두 결과는 같아서, 보상은 게임 안 우편함으로 들어옵니다.

두 방법을 모두 시도해볼 필요는 없습니다. 코드는 한 번 등록되면 다른 경로로 다시 넣어도 "이미 사용된 코드"로 처리되므로, 편한 쪽 하나만 골라 진행하면 됩니다.

SOL: 인챈트 쿠폰 등록 방법

SOL: 인챈트 쿠폰 코드 페이지에서 코드를 확인한 뒤 넷마블 쿠폰 등록 페이지(coupon.netmarble.com/sol)에서 입력합니다. 이 게임은 계정당 한 번만 코드를 등록할 수 있다는 점이 다른 두 게임과 가장 큰 차이입니다. 여러 코드를 한꺼번에 확보했다면 순서를 미리 정해두고, 가장 필요한 코드부터 등록하는 것이 안전합니다.

코드가 안 먹힐 때 자주 틀리는 점

게임 흔한 실수 확인할 점
킹스로드 PID 입력란을 찾다가 시간을 허비 이 게임은 PID 입력란이 없습니다. 로그인 계정만 맞으면 됩니다
나 혼자만 레벨업: 어라이즈 인게임과 웹에서 같은 코드를 두 번 입력 한 번만 등록되며, 두 번째 시도는 이미 사용된 코드로 뜹니다
SOL: 인챈트 계정당 1회 제한을 모르고 두 번째 코드부터 등록 시도 첫 코드 등록 전에 어떤 코드를 넣을지 먼저 정해두세요

자주 묻는 질문

넷마블 쿠폰은 PC와 모바일 중 어디서 등록해야 하나요?

coupon.netmarble.com 페이지는 브라우저만 있으면 접속되므로 PC와 모바일 모두 같은 방식으로 등록할 수 있습니다. 게임을 실행하지 않은 상태에서도 코드 등록 자체는 가능하지만, 보상을 받으려면 이후 게임을 실행해 우편함을 확인해야 합니다.

코드를 다른 게임 등록 페이지에 넣으면 어떻게 되나요?

게임마다 등록 주소(/got, /sololv, /sol 등)가 다르기 때문에 다른 게임 페이지에 코드를 넣으면 대부분 유효하지 않은 코드로 처리됩니다. 코드는 해당 게임 전용으로 발급되므로, 정확한 게임의 등록 주소인지 먼저 확인하는 것이 중요합니다.

등록은 됐는데 보상이 안 보여요.

넷마블 게임 대부분은 코드 등록 즉시 지급이 아니라 게임 안 우편함으로 보상을 보냅니다. 등록 후 게임을 실행해 우편함을 확인하지 않으면 보상을 못 받은 것으로 착각하기 쉽습니다. 우편함이 가득 차 있으면 새 우편이 안 올 수 있으니 미리 비워두는 것도 도움이 됩니다.

넷마블 쿠폰은 등록 창구가 게임마다 조금씩 다르다는 점만 기억하면 실패할 이유가 크게 줄어듭니다. 코드를 확인한 게임의 전용 페이지에서 로그인 계정을 맞춰 순서대로 등록하고, 등록 후에는 반드시 게임 안 우편함을 확인하는 습관을 들이면 됩니다.
