그로우 어 가든 코드 총정리: 입력 방법과 보상 확인하기

겜대·ECM 쿠폰 운영자·2026.09.26 작성

그로우 어 가든(Grow a Garden) 코드는 게임 화면의 설정(톱니바퀴) 아이콘 → Redeem Codes 칸에 입력하면 됩니다. 다만 이 게임은 코드로 재화나 씨앗을 직접 주지 않고 코스튬·장식 아이템 위주로 보상하는 편이라, 다른 로블록스 게임과 보상 성격이 다릅니다. 아래에서 입력 방법과 코드가 언제·어디서 올라오는지, 안 먹힐 때 확인할 점을 순서대로 정리했습니다.

그로우 어 가든이란

그로우 어 가든은 Splitting Point Studios가 만든 로블록스 농장 키우기 게임입니다. 씨앗을 심고 작물을 키워 수확한 뒤 판매하거나 펫을 키우는 방식으로, 2025년부터 로블록스 내에서 꾸준히 상위권 인기를 유지해 온 농장 장르 대표작 중 하나입니다. 진입장벽이 낮고 짧은 시간에도 진행이 가능해 캐주얼하게 즐기는 이용자가 많습니다.

같은 로블록스라도 게임마다 코드 입력 위치와 보상 방식이 다릅니다. 그로우 어 가든은 코드를 게임 진행용 재화보다 수집·꾸미기용 아이템으로 지급하는 편이라, 코드를 놓쳐도 게임 진행 자체에는 큰 영향이 없습니다. 다만 한정 코스튬이나 협업 아이템은 기간이 지나면 다시 받기 어려운 경우가 많아, 확인되는 즉시 입력해두는 것이 좋습니다.

코드 입력하는 방법

코드는 게임 플레이 화면 오른쪽 위 설정(톱니바퀴) 아이콘을 누르면 나오는 메뉴 안에 있습니다.

  1. 그로우 어 가든 게임에 접속한다.
  2. 화면 위쪽 톱니바퀴(설정) 아이콘을 누른다.
  3. Redeem Codes 칸에 코드를 정확히 입력한다.
  4. Claim 버튼을 눌러 보상을 받는다.

코드는 대소문자를 구분하는 영문·숫자 조합이 대부분이라 띄어쓰기 없이 그대로 붙여넣는 것이 안전합니다. 지금 실제로 쓸 수 있는 코드 목록은 그로우 어 가든 쿠폰 페이지에서 확인할 수 있습니다. 이 페이지는 코드가 만료되면 목록에서 내리는 방식으로 관리되기 때문에, 직접 코드를 계속 검색하는 것보다 확인이 빠릅니다.

코드가 주는 보상 종류

그로우 어 가든 코드는 게임 진행에 직접 쓰이는 재화보다 코스튬이나 장식 아이템으로 주어지는 경우가 많습니다. 이 점이 씨앗·코인을 바로 주는 다른 로블록스 파밍 게임과 다른 부분입니다.

보상 유형설명
코스튬캐릭터에 입히는 한정 의상. 대부분 만료일이 따로 공지되지 않는다.
장식 아이템농장을 꾸미는 오브젝트. 이벤트·협업 기념으로 나오는 경우가 많다.

코드가 안 먹힐 때 확인할 점

  • 대소문자와 띄어쓰기를 다시 확인한다. 앞뒤 공백이 하나만 있어도 인식되지 않는다.
  • 코드를 복사했다면 붙여넣기 후 남는 줄바꿈이나 특수문자가 없는지 본다.
  • 위 방법으로도 안 되면 개발팀이 이미 코드를 닫았을 가능성이 크다. 인터넷에 떠도는 코드 중에는 만료된 것이 섞여 있으므로, 등록일이 표시된 곳에서 확인하는 것이 안전하다.
  • 계정을 새로 만들었거나 최근에 접속하지 않았다면, 게임 내 업데이트가 먼저 적용된 뒤에 코드 입력 메뉴가 정상적으로 뜨는지 한 번 재접속해서 확인해본다.

새 코드는 언제, 어디서 올라오나

코드는 개발팀이 직접 발급합니다. 로블록스 게임 페이지 설명란, 개발팀 공식 X(트위터), 공식 디스코드 공지에 먼저 올라오는 경우가 많고, 업데이트나 방문자 수 마일스톤을 기념해 나오는 경향이 있습니다. 다만 정확한 주기가 정해져 있지는 않아 "며칠마다 나온다"고 단정하기는 어렵습니다. 최신 코드는 그로우 어 가든 쿠폰 페이지에서 계속 갱신되니 즐겨찾기해두면 편합니다. 코드 입력 화면이 게임마다 조금씩 다르다는 점이 궁금하다면 블록스 프루트 코드 쓰는 법과 비교해봐도 좋습니다.

자주 묻는 질문

그로우 어 가든 코드는 어디서 입력하나요?

화면 위쪽 설정(톱니바퀴) 아이콘을 누르면 나오는 Redeem Codes 칸에 입력하고 Claim을 누르면 됩니다.

코드로 씨앗이나 코인도 받을 수 있나요?

확인된 코드는 대부분 코스튬이나 장식 아이템을 줍니다. 씨앗·코인 지급 여부는 코드마다 다를 수 있으므로 입력 전 보상 내용을 먼저 확인하는 것이 좋습니다.

"유효하지 않은 코드"라고 나오면 어떻게 하나요?

먼저 대소문자와 띄어쓰기를 다시 확인하세요. 그래도 안 된다면 개발팀이 코드를 이미 닫았을 가능성이 높으니, 등록일이 표시된 페이지에서 지금 쓸 수 있는 코드인지 다시 확인하는 것이 좋습니다.

그로우 어 가든은 코드보다 농장을 꾸준히 키우는 재미가 중심인 게임이지만, 가끔 올라오는 코드를 챙기면 코스튬이나 장식을 무료로 얻을 수 있습니다. 코드는 만료되면 다시 쓸 수 없으니, 확인되는 대로 바로 입력해두는 것을 추천합니다.
