애니메 뱅가드 코드 총정리: 입력 위치와 보상 종류, 레벨 제한 확인법

겜대·ECM 쿠폰 운영자·2026.09.27 작성

애니메 뱅가드(Anime Vanguards) 코드는 화면 오른쪽의 Profile 버튼 → Codes 메뉴에서 입력합니다. 보상은 젬(Gem)이나 골드 같은 재화보다 트레이트 리롤권·메모리아 조각 같은 육성용 아이템이 중심이라, 다른 로블록스 타워 디펜스 게임과는 보상 구성이 조금 다릅니다. 일부 코드는 레벨 제한이 걸려 있어 낮은 레벨에서는 입력해도 수령이 안 될 수 있습니다. 아래에서 입력 순서와 보상 종류, 레벨 제한 코드를 구분하는 법을 정리했습니다.

애니메 뱅가드란

애니메 뱅가드는 로블록스에서 서비스되는 애니메이션풍 타워 디펜스 게임으로, 유닛(뱅가드)을 소환해 웨이브를 막는 방식입니다. 유닛 강화에 필요한 트레이트 리롤이나 메모리아 조각 같은 소모 아이템이 많아, 코드로 이런 육성 재료를 미리 챙겨두면 초반 성장 속도에 도움이 됩니다. 개발팀은 업데이트나 시즌 이벤트 시점에 맞춰 코드를 공개하는 편입니다.

로블록스는 게임마다 코드 입력 UI가 제각각이라, 블록스 프루트 코드 쓰는 법에서 다룬 X(트위터) 아이콘 방식과 달리 애니메 뱅가드는 프로필 메뉴 안에 입력 칸이 숨어 있는 구조입니다. 처음 코드를 찾는 경우 이 차이 때문에 헤매기 쉽습니다.

코드 입력하는 방법

입력 위치만 알면 절차는 간단하지만, 코드는 대소문자를 구분하므로 복사·붙여넣기를 권합니다.

  1. 지금 쓸 수 있는 코드를 확인합니다. 코드는 애니메 뱅가드 쿠폰 페이지에서 하루 두 번 갱신됩니다.
  2. 게임 화면 오른쪽의 Profile 버튼을 누릅니다.
  3. Codes 메뉴를 선택하고 입력 칸에 코드를 붙여넣습니다.
  4. Redeem을 누르면 보상이 즉시 지급됩니다.

코드로 받을 수 있는 보상 종류

애니메 뱅가드 코드는 재화보다 육성 재료 위주로 지급됩니다. 크게 나누면 다음과 같습니다.

보상 유형 설명
트레이트 리롤 유닛의 특성(트레이트)을 다시 뽑을 수 있는 소모 아이템. 가장 흔한 보상입니다.
메모리아 조각 유닛 강화에 쓰이는 재료. 일정 개수를 모아야 효과가 있습니다.
젬 · 골드 기본 재화. 다른 보상과 묶여서 나오는 경우가 많습니다.
특수 토큰류 컨트롤러 토큰·카피캣 토큰 등 특정 콘텐츠 전용 재료. 일반 재화보다 희귀합니다.

일부 코드는 레벨 10 또는 30 이상이어야 정상 수령됩니다. 저레벨 계정으로 입력했는데 보상이 안 들어왔다면 코드가 만료된 것이 아니라 레벨 제한에 걸렸을 가능성을 먼저 의심해보는 것이 좋습니다. 코드별 정확한 레벨 조건과 만료일은 애니메 뱅가드 쿠폰 페이지의 표에서 확인할 수 있습니다.

코드가 안 먹힐 때 확인할 점

  • 레벨 제한 — 일부 코드는 레벨 10·30 이상에서만 정상 수령됩니다. 계정 레벨을 먼저 확인하세요.
  • 대소문자·띄어쓰기 — 로블록스 코드는 대소문자를 구분합니다. 손으로 옮기지 말고 복사해서 붙여넣으세요.
  • 계정당 한 번 — 같은 코드는 한 계정에서 한 번만 됩니다. "이미 사용됨"이 뜨면 이전에 받은 것입니다.
  • 예고 없는 종료 — 개발팀은 공지 없이 코드를 닫습니다. 조건을 다 확인했는데도 안 되면 이미 닫힌 코드일 가능성이 큽니다.

새 코드는 언제, 어디서 올라오나

정해진 주기는 없습니다. 업데이트나 시즌 콘텐츠 공개, 소셜 채널 팔로워·좋아요 목표 달성, 서버 오류에 대한 보상 등 다양한 계기로 코드가 풀립니다. 로블록스 게임 페이지 설명란이나 개발팀 공식 채널에 먼저 공지되는 경우가 많으므로, 정확한 시점은 공식 채널에서 확인하는 것이 가장 안전합니다. "지금 뜨는 코드"라며 계정 정보나 로그인 정보를 요구하는 글은 게임 쿠폰 완벽 가이드에서 설명하듯 대부분 가짜이니 주의가 필요합니다.

자주 묻는 질문

애니메 뱅가드 코드는 어디서 입력하나요?

화면 오른쪽 Profile 버튼을 누르고 Codes 메뉴를 선택하면 나오는 입력 칸에 코드를 넣고 Redeem을 누르면 됩니다.

코드를 넣었는데 보상이 안 들어와요.

먼저 대소문자와 띄어쓰기를 확인하고, 그다음 그 코드에 레벨 제한이 있는지 확인해보세요. 조건을 충족하는데도 안 된다면 이미 만료된 코드일 수 있습니다.

다른 로블록스 게임도 입력 위치가 같나요?

아니요, 게임마다 다릅니다. 애니메 뱅가드는 Profile 메뉴 안에 있지만 블록스 프루트처럼 화면 밖에 별도 아이콘을 두는 게임도 있습니다. 게임을 바꿔 코드를 넣을 때는 그 게임 쿠폰 페이지에서 입력 위치를 다시 확인하는 것이 안전합니다.

애니메 뱅가드 코드는 재화보다 유닛 육성 재료 위주라 당장 눈에 띄는 효과는 작아 보일 수 있지만, 트레이트 리롤과 메모리아 조각을 미리 모아두면 이후 강화 단계에서 체감이 큽니다. 레벨 제한이 있는 코드는 조건을 채운 뒤 입력하고, 최신 코드는 쿠폰 페이지에서 확인하는 습관을 들이는 것을 추천합니다.
