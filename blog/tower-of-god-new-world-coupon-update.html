신의 탑: 새로운 세계 쿠폰 코드 입력 방법과 10월14일 업데이트 정리

GamerDaddy·ECM 쿠폰 운영자·2026.10.15 작성·2026.10.19 수정

신의 탑: 새로운 세계 쿠폰은 안드로이드는 게임 안의 코드 입력 버튼에서, 아이폰은 넷마블 쿠폰 웹페이지에서 넣는다. 다만 2026년 10월15일 기준으로 등록된 코드가 없다. 대신 넷마블은 10월14일 공식 업데이트 안내로 신규 동료 '엔도르시'를 비롯한 콘텐츠 업데이트를 열었다. 이 글에서 입력 방법과 자주 틀리는 점, 업데이트로 바뀐 내용, 다음 코드가 뜨면 바로 확인하는 법을 정리한다.

쿠폰 코드, 지금은 왜 없을까

신의 탑: 새로운 세계는 넷마블이 2023년 7월 출시해 올해 7월 3주년을 맞은 수집형 RPG다. ECM 쿠폰은 공식 카페 공지와 인벤 기사를 4시간마다 확인하는데, 10월15일 현재 등록 기준(게임사 공식 채널이나 독립된 출처 2곳 확인)을 통과한 코드가 없다. 다른 사이트에 코드가 떠 있어도 만료됐거나 확인되지 않은 것일 수 있으니, 등록일이 적힌 곳에서 확인하는 게 안전하다. 지금 살아 있는 코드는 신의 탑: 새로운 세계 쿠폰 코드 페이지에서 확인할 수 있다. 새 코드가 뜨면 바로 올라온다.

쿠폰 코드 입력 방법

공식 쿠폰 사용 방법 안내에 따르면 입력 경로가 안드로이드와 아이폰에서 다르다. 안드로이드는 게임 안에서, 아이폰은 넷마블이 따로 만든 웹페이지에서 처리하는 방식이다.

기기입력 경로보상 수령
안드로이드[프로필] → [설정] → [코드 입력]에서 쿠폰 이벤트 선택 후 코드 입력게임 내 우편함
아이폰넷마블 쿠폰 웹페이지에 회원번호(프로필 하단 ID)와 코드 입력게임 내 우편함

가장 자주 틀리는 부분은 서버 확인이다. 공식 안내 기준 게임 안에서 입력한 코드는 접속해 있는 서버를 기준으로 지급되고, 사용한 뒤에는 다른 서버로 보상을 옮기거나 코드를 복구해 주지 않는다. 코드별 사용 횟수는 공통 안내에 적혀 있지 않으니, 코드를 알린 공지에서 함께 확인하는 게 좋다. 넷마블 계열 게임의 코드 등록 방식이 비슷하니, 다른 게임도 헷갈린다면 넷마블 쿠폰 등록 방법과 자주 실패하는 이유를 같이 보면 도움이 된다.

10월14일 업데이트로 바뀐 것

넷마블은 10월14일 신의 탑: 새로운 세계의 콘텐츠 업데이트를 공식 발표했다. 핵심은 자 속성 원거리 SSR+ 등급 신규 동료 '[반역의 공주] 엔도르시' 추가다. 엔도르시는 필살기로 적에게 피해를 주며 밀어내고, 기본 공격으로 쌓은 '가속' 중첩을 소모해 위력을 올리는 방식이다. 같이 공개된 전용 의상 '제로백'도 확인됐다.

콘텐츠 쪽에서는 10월 14일 인게임 이벤트 안내 기준 '[FUG의 수장] 루슬렉' 강림 소환 복각과 기억의 미궁「루슬렉」복각이 10월 28일(수) 08:49:59(KST)까지 열린다. 연합 토벌전 보스는 '전격의 철갑장어'로 바뀌었고, 제작소에서 얻는 자 속성 SSR+ 신규 부유선 '글롬스파이어'가 추가됐다. 모험 챕터(376F~380F) 확장과 코어 레벨 80 확장도 함께 들어갔다. 공식 업데이트 안내에는 이미지와 수치가 테스트 빌드 기준이라 실제 게임과 일부 다를 수 있다는 단서가 붙어 있으니, 세부 수치는 게임 안에서 다시 확인하는 걸 추천한다.

10월 14일 상점 품목 안내에 따르면 루슬렉 복각 기념으로 모든 선별인원에게 '10% 웹상점 할인 쿠폰'이 지급됐다. 게임 내 코드 입력과는 다른 웹상점 전용 할인 쿠폰으로, 사용 기한은 공식 웹상점의 보유 쿠폰함에서 확인하면 된다. 업데이트 기념 인게임 이벤트도 대부분 10월 28일(수) 08:49:59까지 이어진다.

다음 코드는 언제, 어떻게 확인할까

넷마블 게임은 보통 공식 카페 공지, 쇼케이스·업데이트 방송, 출시 기념 이벤트에서 코드를 낸다. 큰 업데이트 때 기념 코드가 같이 나오는 경우도 있으니, 10월28일까지 진행되는 이벤트 기간 중 공식 카페를 눈여겨볼 만하다. ECM 쿠폰은 공식 채널을 4시간마다 확인해서, 독립된 출처 2곳에서 확인된 코드만 등록한다. 신의 탑 코드 페이지를 즐겨찾기해 두면 새 코드가 올라올 때 바로 확인할 수 있고, 다른 넷마블 게임처럼 일부 코드가 서버·시기 한정일 수 있으니 등록일도 같이 확인하는 게 좋다. 참고로 같은 넷마블 게임인 왕좌의 게임: 킹스로드도 코드 등록 방식이 비슷해 처음 코드를 입력해 보는 유저라면 비교해 볼 만하다.

자주 묻는 질문

신의 탑: 새로운 세계 쿠폰 코드는 지금 없나요?

2026년 10월15일 기준으로 ECM 쿠폰 등록 기준을 통과한 코드가 없다. 새 코드가 확인되면 코드 페이지에 등록일과 함께 바로 올라온다.

아이폰에서는 왜 게임 안에서 코드를 못 넣나요?

넷마블이 아이폰용으로는 게임 밖 웹페이지를 따로 준비했기 때문이다. 회원번호(프로필 하단 ID)와 코드를 그 페이지에 입력하면 게임 내 우편함으로 보상이 온다.

복각 소환 '루슬렉'은 언제까지 열리나요?

넷마블의 10월 14일 인게임 이벤트 안내 기준 10월 28일(수) 08:49:59(KST)까지다. 연합 토벌전 보스는 10월 14일 업데이트 이후 '전격의 철갑장어'로 바뀌었다.

신의 탑: 새로운 세계는 지금은 등록된 코드가 없지만, 10월14일 업데이트로 콘텐츠가 꽤 늘었고 10월28일까지 복각 소환과 기념 이벤트가 이어진다. 이 기간에 기념 코드가 나올 가능성이 있으니, 코드 페이지를 즐겨찾기해 두고 입력 방법만 미리 익혀 두면 코드가 뜨는 즉시 바로 받을 수 있다.
