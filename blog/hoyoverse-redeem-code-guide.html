원신, 붕괴: 스타레일, 젠레스 존 제로는 모두 호요버스(HoYoverse)가 만든 게임이라 교환 코드 입력 방식이 거의 같습니다. 다만 게임마다 교환 페이지 주소와 인게임 메뉴 위치가 조금씩 달라, 다른 게임을 하다 넘어온 사람은 헷갈리기 쉽습니다. 결론부터 말하면 세 게임 모두 웹 교환 페이지에서 계정으로 로그인해 코드를 붙여 넣거나, 게임 안 메뉴에서 바로 입력하면 됩니다. 아래에서 게임별 정확한 주소와 입력 순서, 코드가 안 먹힐 때 확인할 점을 정리했습니다.

호요버스 게임들이 같은 방식을 쓰는 이유

원신, 스타레일, 젠존제는 같은 회사가 만들고 운영하는 게임이라 계정 시스템과 교환 코드 처리 방식을 공유합니다. 그래서 코드 형식(영문 대문자와 숫자 조합)과 입력 절차의 큰 흐름은 동일하지만, 게임마다 교환 페이지 주소와 게임 내 메뉴 이름은 따로 운영됩니다. 원신은 '설정 > 계정' 메뉴에서, 스타레일은 '휴대폰' 메뉴에서, 젠존제는 '메뉴 > 기타'에서 교환 코드 항목을 찾을 수 있습니다. 세 게임을 같이 하는 사람이라면 이 차이만 알아두면 헷갈릴 일이 크게 줄어듭니다.

게임 웹 교환 페이지 인게임 메뉴 위치

주소를 외울 필요는 없습니다. 지금 쓸 수 있는 코드와 만료일은 ECM 쿠폰의 게임별 코드 페이지에서 실시간으로 확인할 수 있습니다. 원신 쿠폰 코드 페이지, 붕괴: 스타레일 쿠폰 코드 페이지, 젠레스 존 제로 쿠폰 코드 페이지에서 코드를 복사한 뒤 아래 순서대로 넣으면 됩니다.

코드 입력 3단계

  1. 코드를 정확히 복사합니다. 영문 대문자와 숫자가 섞여 있어 직접 타이핑하면 오타가 나기 쉬우므로 복사·붙여넣기를 권장합니다.
  2. 웹 교환 페이지에 접속해 보상을 받을 계정으로 로그인하거나, 게임을 실행해 위 표의 메뉴로 이동합니다.
  3. 코드를 붙여 넣고 확인을 누릅니다. 보상은 즉시 지급되지 않고 대부분 게임 안 우편함으로 들어옵니다.

세 게임 모두 코드는 계정당 한 번만 쓸 수 있습니다. 여러 서버나 캐릭터로 다시 넣어도 중복 지급되지 않으니, 처음부터 보상을 받을 계정이 맞는지 확인하고 로그인하는 것이 중요합니다.

코드가 안 먹힐 때 확인할 점

증상 가장 흔한 원인
"유효하지 않은 코드"라고 뜬다 대소문자 오타, 앞뒤 공백. 직접 타이핑 대신 복사·붙여넣기 권장
등록은 됐는데 보상이 안 보인다 게임 안 우편함을 확인하지 않았거나, 우편함이 가득 차 새 우편이 안 들어온 경우
"이미 사용된 코드"라고 뜬다 같은 계정으로 이전에 등록했거나 코드 자체가 만료됨

세 가지를 다 확인해도 안 된다면 코드 자체가 만료됐을 가능성이 큽니다. 상시 코드로 안내된 것도 게임사가 예고 없이 닫는 경우가 있으니, 안 되면 만료된 것으로 보고 최신 코드를 다시 확인하는 것이 빠릅니다.

자주 묻는 질문

원신, 스타레일, 젠존제 코드를 한 계정으로 같이 쓸 수 있나요?

아니요. 같은 호요버스 로그인 계정을 쓰더라도 게임마다 데이터가 따로 운영되기 때문에 게임별로 코드를 각각 입력해야 합니다. 원신에서 등록한 코드가 스타레일이나 젠존제 보상으로 자동으로 넘어가지 않습니다.

웹 교환 페이지와 인게임 입력 중 뭐가 더 편한가요?

결과는 같습니다. 오타를 줄이려면 브라우저에서 코드를 복사해 웹 페이지에 붙여 넣는 방식이 조금 더 안전하고, 이미 게임을 켜둔 상태라면 인게임 메뉴에서 바로 입력해도 무방합니다.

코드 유효기간은 어떻게 확인하나요?

게임 공식 소셜미디어나 공지사항에서 확인하는 것이 가장 정확합니다. 정확한 최신 정보는 공식 사이트에서 확인하는 것이 원칙이며, ECM 쿠폰이 확인한 코드는 게임별 쿠폰 페이지에 등록일과 함께 표시하니 입력 전에 참고하면 됩니다.

원신, 스타레일, 젠존제는 같은 회사 게임이라 입력 절차의 틀은 같지만, 정확한 주소와 메뉴 이름은 게임마다 다릅니다. 이 표를 기억해두고 코드를 입력하기 전에는 게임별 쿠폰 페이지에서 최신 코드와 만료일을 먼저 확인하는 습관을 들이는 것을 추천합니다.
