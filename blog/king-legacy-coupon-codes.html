킹 레거시 코드 9종 총정리: 입력 방법과 보상 확인법

겜대·ECM 쿠폰 운영자·2026.10.11 작성

킹 레거시(King Legacy)는 로블록스에서 서비스되는 원피스풍 해적 RPG로, 코드는 화면 하단 Menu 버튼을 눌러 나오는 상점(바스켓 모양 아이콘) 안 입력 칸에 넣습니다. ECM 쿠폰이 2026년 10월 기준으로 확인한 코드는 9개이며, 대부분 경험치 부스트나 골드를 주지만 일부는 과거 특정 조건을 충족해야만 받을 수 있는 '조건부 코드'라 아무 계정이나 넣는다고 똑같이 보상이 나오지 않습니다. 이 글에서는 입력 위치부터 코드별 보상 성격, 입력했는데 안 먹히는 이유까지 정리했습니다.

킹 레거시는 어떤 게임인가

킹 레거시는 개발사 Thai Piece가 만든 로블록스 게임으로, 항해하며 섬을 돌고 악마의 열매로 추정되는 과일 능력을 익혀 전투하는 구조가 원피스 세계관과 닮아 꾸준히 인기를 끌고 있습니다. 같은 장르의 블록스 프루트만큼 코드 발행이 잦지는 않지만, 업데이트 전후로 드물게 코드를 풀어 왔습니다.

코드 입력하는 방법

킹 레거시의 코드 입력 칸은 전투 메뉴가 아니라 상점 메뉴 안에 숨어 있어 처음 찾을 때 헤매기 쉽습니다.

  1. 화면 하단의 Menu 버튼을 누릅니다.
  2. 메뉴 안에서 바스켓(장바구니) 모양의 상점 아이콘을 선택합니다.
  3. 상점 화면 하단에 있는 코드 입력 칸에 코드를 붙여넣습니다.
  4. Redeem 버튼을 눌러 보상을 받습니다. 지금 쓸 수 있는 코드는 킹 레거시 쿠폰 페이지에서 확인할 수 있습니다.

코드로 받는 보상 종류

ECM 쿠폰이 확인한 9개 코드는 보상 성격에 따라 아래처럼 나뉩니다. 특히 젬을 주는 코드 두 개는 아무에게나 똑같이 적용되지 않는 조건부 코드라는 점이 다른 로블록스 게임과 다른 특징입니다.

보상 유형 설명
경험치 부스트 일정 시간 동안 획득 경험치를 2배로 올려주는 코드로, 9개 중 가장 많은 비중을 차지합니다.
골드 게임 내 재화인 골드를 즉시 지급하는 코드로, 초반 장비·스킬 구매 자금으로 바로 쓸 수 있습니다.
젬(조건부) 과거 '업데이트7' 이전에 특정 색 드래곤을 보유했는지 여부에 따라 지급량이 달라지는 코드입니다. 조건을 충족하지 못한 계정은 더 적은 양이 지급되거나 아예 반영되지 않을 수 있습니다.
무료 스탯 초기화 능력치를 잘못 분배했을 때 다시 찍을 수 있게 해주는 코드로, 재화 소모 없이 스탯을 리셋해 줍니다.

이 중 한 코드는 'Sea King Games'라는 로블록스 그룹에 가입해야만 보상이 적용되는 조건이 붙어 있습니다. 그룹 미가입 상태로 입력하면 코드 자체는 '사용됨' 처리되고 보상은 받지 못하는 경우가 있으니, 코드를 쓰기 전에 그룹 가입 여부부터 확인하는 것이 좋습니다.

코드가 안 먹힐 때 체크리스트

  • 조건부 코드인지 먼저 확인 — 젬 보상 코드는 과거 드래곤 보유 여부, 일부 코드는 특정 그룹 가입 여부에 따라 보상이 달라집니다. "코드가 적용됐다"는 메시지가 떠도 기대한 보상이 안 들어올 수 있습니다.
  • 대소문자 구분 — 로블록스 코드는 대소문자를 구분하므로 직접 입력하지 말고 복사해서 붙여넣는 편이 안전합니다.
  • 계정당 한 번 — 같은 코드를 이미 받았다면 다시 넣어도 보상은 중복 지급되지 않습니다.
  • 입력 칸 위치 재확인 — Menu 버튼이 아니라 전투·인벤토리 메뉴에서 코드 칸을 찾다가 못 찾는 경우가 많습니다. 반드시 상점(바스켓) 아이콘 안을 확인하세요.

자주 묻는 질문

코드를 입력했는데 보상이 하나도 안 들어왔어요.

젬을 주는 두 코드처럼 과거 특정 조건(드래곤 보유 이력 등)을 충족해야 하는 조건부 코드일 가능성이 있습니다. 조건을 충족하지 못한 계정은 적은 양만 지급되거나 보상이 없을 수 있으니, 다른 코드부터 먼저 확인해 보세요.

코드 입력 칸을 못 찾겠어요.

전투 화면이나 인벤토리가 아니라 화면 하단 Menu 버튼을 누른 뒤 나오는 상점(바스켓 모양) 아이콘 안에 있습니다. 다른 로블록스 게임은 입력 위치가 제각각이라 헷갈리기 쉬운데, 로블록스 코드 입력 위치 총정리에서 게임별 위치를 함께 확인할 수 있습니다.

킹 레거시 코드는 얼마나 자주 나오나요?

정해진 발행 주기는 없습니다. 같은 장르의 다른 로블록스 게임보다 코드를 푸는 빈도 자체가 낮은 편이라, 새 코드가 나오면 킹 레거시 쿠폰 페이지에서 갱신되는 목록을 주기적으로 확인하는 편이 가장 확실합니다.

킹 레거시는 코드 개수 자체는 많지 않지만, 조건부 보상이 섞여 있어 다른 로블록스 게임보다 "왜 안 되지"라는 질문이 자주 나오는 편입니다. 로블록스 코드 전반의 운영 방식이 궁금하다면 게임 쿠폰 완벽 가이드도 함께 참고하세요.
