애니메 뱅가드 코드 27일 기록: 처음 확인한 날과 목록에 머문 기간

GamerDaddy·ECM 쿠폰 운영자·2026.10.19 작성

ECM 쿠폰은 9월 23일부터 10월 19일까지 27일 동안 애니메 뱅가드 코드 38개를 새로 확인해 목록에 올렸어요. 새 코드를 처음 확인한 날은 6일(9/23·9/26·9/29·10/5·10/12·10/17)이었고, 10월 19일 기준으로 19개는 목록에서 제외했고 19개는 아직 목록에 있어요. 같은 날 처음 확인한 코드끼리도 목록에 머문 기간은 달랐어요. 9월 29일에 처음 확인한 9개는 모두 10월 1일 확인 때 목록에서 뺐지만, 9월 26일에 확인한 10개는 1일·5일·11일로 갈렸어요. 오래 남는 코드가 있다고 새 코드도 오래 남을 거라 기대하기 어려우니, 보이면 그날 넣는 편이 안전해요.

아래 숫자는 ECM 쿠폰이 코드마다 남기는 기록(처음 확인한 날, 목록에서 제외한 날)을 직접 센 값이에요. 개발팀이 발표한 발급일·만료일이 아니라는 점이 이 글을 읽는 핵심이라, 어떻게 셌고 이 기록으로 알 수 없는 것이 무엇인지부터 적어 둘게요.

어떻게 셌고, 무엇을 알 수 없나요

  • 기간: 2026년 9월 23일~10월 19일(27일). ECM 쿠폰이 애니메 뱅가드를 목록에 넣은 날부터 이 글을 고친 날까지예요.
  • 최초 확인일: 개발팀이 코드를 낸 날이 아니라, ECM 쿠폰이 공식 채널이나 서로 다른 출처 2곳에서 확인해 올린 날이에요(등록 기준). 로블록스 코드는 하루 두 번 확인해서 실제 공개보다 늦을 수 있어요.
  • 목록에서 제외한 날: ECM 쿠폰이 확인할 때 쓸 수 없다고 보고 목록에서 뺀 날이에요. 공식 만료일이 아니에요. 애니메 뱅가드는 코드 만료일을 따로 공지하지 않았고, 실제로 닫힌 때는 이보다 이를 수 있어요. ECM의 판단이 틀릴 때도 있어요. 9/23에 확인한 코드 3개는 10/18 갱신 때 목록에서 뺐다가, 다시 확인해 10/19 갱신 때 되돌렸어요. 이 글에서는 이 3개를 목록에 있는 코드로 셌어요.
  • 추적 첫날(9/23)의 9개: 게임을 목록에 처음 넣은 날, 그때 쓸 수 있던 코드를 한꺼번에 올린 거예요. 언제 나온 코드인지 알 수 없어서 최초 확인일 간격과 목록에 머문 기간을 볼 때는 따로 표시했어요.
  • 아직 목록에 있는 코드: 관측이 끝나지 않은 코드예요. 표에 적은 기간은 "10/19까지 최소 이만큼 목록에 있었다"는 뜻이에요.
