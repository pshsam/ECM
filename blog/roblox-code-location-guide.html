로블록스 코드 입력 위치 총정리: 게임별로 버튼 찾는 법

겜대·ECM 쿠폰 운영자·2026.09.29 작성

로블록스는 게임마다 코드 입력 버튼 위치가 전부 다릅니다. 한 게임에서 쓰던 방식을 다른 게임에 그대로 적용하면 아무리 찾아도 입력 칸이 안 보이는 이유가 이 때문입니다. 이 글은 인기 로블록스 게임 15종의 코드 입력 위치를 한 번에 정리해, 버튼을 못 찾아 헤매는 시간을 줄이는 데 목적이 있습니다. 게임별 실제 코드 목록은 각 게임 쿠폰 페이지에서 갱신되므로, 여기서는 "어디를 눌러야 하는지"에 집중합니다.

왜 로블록스는 게임마다 코드 입력 위치가 다른가

로블록스는 하나의 플랫폼이지만, 그 안의 게임(익스피리언스)은 각각 다른 개발팀이 독립적으로 만듭니다. 코드 입력 기능도 로블록스가 공통 제공하는 게 아니라 개발팀이 직접 UI를 짜 넣는 구조라, 톱니바퀴 아이콘·상점 메뉴·전용 Codes 버튼 등 게임마다 구현 방식이 갈립니다. 그래서 "로블록스 코드 넣는 법"을 한 번에 외워둘 수 없고, 게임별로 확인하는 수밖에 없습니다.

코드 입력 위치, 크게 3가지 유형으로 나뉜다

15개 게임을 직접 살펴본 결과 입력 위치는 대체로 세 유형으로 묶입니다.

  • 설정(톱니바퀴) 경유형 — 화면 구석의 설정 아이콘을 눌러야 코드 칸이 나옵니다. 비 스웜 시뮬레이터, 그로우 어 가든이 해당합니다.
  • 전용 Codes 버튼형 — 로비나 화면 한쪽에 'Codes'라고 적힌 버튼이 따로 있습니다. 애니메 뱅가드, 바스켓볼 제로, 블레이드 볼, 블루록: 라이벌, 피쉬, 스틸 어 브레인랏, 99 나이츠 인 더 포레스트가 이 방식입니다.
  • 상점·메뉴 경유형 — 상점이나 메인 메뉴 안쪽에 코드 칸이 숨어 있습니다. 다후드, 킹 레거시, 플랜츠 vs 브레인랏, 신도 라이프가 여기 속합니다.

블록스 프루트는 톱니바퀴나 선물 상자 아이콘 둘 다로 접근할 수 있어 두 유형에 걸쳐 있습니다. 자세한 입력 순서는 블록스 프루트 코드 쓰는 법에서 단계별로 확인할 수 있습니다.

코드 입력할 때 공통으로 확인할 점

  • 대소문자 구분 — 로블록스 코드는 대소문자를 그대로 봅니다. 손으로 옮겨 적지 말고 복사·붙여넣기로 입력하는 게 안전합니다.
  • 계정당 한 번 — 같은 코드는 계정마다 한 번만 적용됩니다. "이미 사용됨" 메시지가 뜨면 예전에 받은 코드입니다.
  • 조건이 걸린 코드 — 바스켓볼 제로나 블루록: 라이벌처럼 그룹 가입·레벨·승수 등 조건이 있는 게임도 있습니다. 조건을 채우지 않으면 정상 코드도 입력이 안 됩니다.
  • 예고 없는 종료 — 개발팀은 별다른 공지 없이 코드를 닫습니다. 위치도 맞고 대소문자도 맞는데 안 된다면 이미 종료된 코드일 가능성이 큽니다.

코드를 챙기는 습관을 게임 장르별로 더 넓게 정리하고 싶다면 게임 쿠폰 완벽 가이드도 함께 참고하면 도움이 됩니다.

자주 묻는 질문

코드 입력 칸을 아무리 찾아도 안 보여요.

위 표에서 해당 게임의 입력 위치를 먼저 확인하세요. 그래도 안 보이면 게임 로딩이 덜 끝났거나, 업데이트로 UI 위치가 바뀌었을 수 있습니다. 잠시 후 다시 접속해 확인하는 것이 좋습니다.

모바일과 PC의 입력 위치가 다른가요?

대부분 같은 위치입니다. 다만 화면이 작은 모바일에서는 아이콘이 작게 표시돼 못 보고 지나치는 경우가 많으니, 화면을 확대해 구석구석 확인하는 게 좋습니다.

코드 입력 위치가 갑자기 바뀌기도 하나요?

네, 개발팀이 UI를 개편하면 입력 위치도 함께 바뀔 수 있습니다. 이 글은 확인 시점 기준으로 정리한 것이라, 위치가 달라졌다면 해당 게임의 쿠폰 페이지에서 최신 안내를 다시 확인하는 것이 정확합니다.

로블록스 코드는 게임마다 위치도, 조건도 제각각이라 처음에는 헷갈리기 쉽습니다. 위 표를 기준으로 한 번만 확인해두면 다음부터는 헤매는 시간 없이 바로 코드를 입력할 수 있습니다.
