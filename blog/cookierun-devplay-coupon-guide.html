쿠키런: 킹덤·크럼블 쿠폰 코드, DevPlay 등록 방법과 받는 법

겜대·ECM 쿠폰 운영자·2026.10.01 작성

쿠키런: 킹덤과 쿠키런: 크럼블은 둘 다 데브시스터즈 게임이라 "쿠폰도 한 곳에서 같이 넣으면 되지 않을까" 생각하기 쉽지만, 실제로는 등록 페이지 주소가 서로 다릅니다. 두 게임 모두 공식 쿠폰 등록 페이지(DevPlay)에서 코드를 넣는다는 공통점은 있지만, 계정을 확인하는 방법과 보상이 들어오는 방식은 게임마다 차이가 있습니다. 이 글에서는 게임별 등록 페이지와 계정 확인법, 보상 수령 방식의 차이를 정리했습니다. 지금 쓸 수 있는 코드 자체는 아래 게임 페이지에서 바로 확인하세요.

쿠키런: 킹덤 쿠폰, 어디서 넣나

쿠키런: 킹덤 쿠폰은 공식 쿠폰 등록 페이지(DevPlay)에서 입력합니다. 안드로이드는 게임 안 ☰ > 환경설정 > 정보 탭에서도 등록할 수 있지만, iOS는 웹페이지로만 등록할 수 있어 기기에 따라 방법이 갈립니다. 등록 페이지에 들어가려면 게임에 연결된 DevPlay 계정이 필요한데, 이 계정 정보도 같은 환경설정 > 정보 탭에서 확인할 수 있습니다.

코드를 넣을 때는 화면에 보이는 코드를 직접 타이핑하기보다 복사해서 붙여 넣는 편이 안전합니다. 숫자 0과 알파벳 O, 대문자 I와 소문자 l을 손으로 옮기다 잘못 입력하는 경우가 많기 때문입니다.

쿠키런: 크럼블 쿠폰, 입력 페이지는 다르다

쿠키런: 크럼블도 같은 DevPlay 플랫폼을 쓰지만, 등록 페이지 주소는 킹덤과 다릅니다. 킹덤 쿠폰 페이지에 크럼블 코드를 넣거나 반대로 넣으면 인식되지 않으니, 플레이 중인 게임에 맞는 페이지로 들어갔는지부터 확인해야 합니다. 크럼블은 킹덤과 달리 인게임 등록 경로에 대한 안내가 따로 없어, 웹 페이지에서 DevPlay 계정 정보와 코드를 넣어 등록하는 방식이 기본입니다.

두 게임 모두 쿠폰은 계정당 한 번만 쓸 수 있습니다. 같은 코드를 다른 서버나 캐릭터로 다시 넣어도 이미 사용한 코드로 처리되어 보상이 추가로 나오지 않습니다.

보상 받는 방식이 서로 다르다

두 게임을 같이 하는 사람이 가장 헷갈려 하는 부분이 보상 수령 방식입니다. 쿠키런: 킹덤은 코드를 등록하면 보상이 보통 게임 안 우편함으로 도착합니다. 우편함이 가득 차 있으면 받지 못할 수 있으니 코드를 넣기 전에 한 번 비워 두는 편이 좋습니다. 반면 쿠키런: 크럼블은 코드를 입력한 뒤 게임을 다시 실행해야 보상이 반영됩니다. 등록 화면에서 성공 메시지를 봤는데 게임 안에서 보상이 안 보인다면, 우편함을 기다리기보다 게임을 완전히 종료했다가 다시 켜보는 쪽이 빠릅니다.

코드를 넣었는데 안 될 때 확인할 점은 게임마다 비슷한 편입니다. 더 자세한 체크리스트는 만료된 쿠폰 코드 확인 가이드에서 다룹니다. 지금 등록할 수 있는 실제 코드는 이 글이 아니라 쿠키런: 킹덤 쿠폰 코드 페이지와 쿠키런: 크럼블 쿠폰 코드 페이지에서 확인하는 편이 정확합니다.

자주 묻는 질문

쿠키런: 킹덤과 크럼블 쿠폰을 같은 페이지에서 등록할 수 있나요?

아니요. 둘 다 DevPlay 플랫폼을 쓰지만 게임별로 등록 페이지 주소가 다릅니다. 플레이 중인 게임에 맞는 페이지에서 입력해야 코드가 인식됩니다.

코드를 넣었는데 "유효하지 않은 코드"라고 나와요.

대소문자와 공백을 다시 확인하세요. 코드가 정확한데도 안 된다면 만료됐거나 이미 같은 계정으로 사용한 코드일 가능성이 큽니다.

코드를 등록하면 보상이 바로 오나요?

쿠키런: 킹덤은 보통 게임 안 우편함으로 들어오고, 쿠키런: 크럼블은 등록 후 게임을 다시 실행해야 보상이 반영됩니다. 둘 다 등록 즉시 게임 화면에 바로 나타나지 않을 수 있습니다.

쿠키런: 킹덤과 크럼블은 같은 회사의 게임이지만 쿠폰 등록 페이지와 보상을 받는 방식이 다르다는 점만 기억해 두면 헷갈릴 일이 줄어듭니다. 코드 자체는 계속 바뀌므로, 입력 전에는 항상 쿠키런: 킹덤 쿠폰 코드 페이지와 쿠키런: 크럼블 쿠폰 코드 페이지에서 최신 상태를 확인하세요.
