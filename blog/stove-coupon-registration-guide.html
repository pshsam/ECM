스토브(STOVE) 쿠폰 등록 방법: 로스트아크·이클립스 코드 넣는 법

겜대·ECM 운영자·2026.09.24 작성

로스트아크와 이클립스: 더 어웨이크닝의 쿠폰 코드는 게임 안이 아니라 스마일게이트의 STOVE 계정으로 로그인하는 별도 웹페이지에서 등록합니다. 게임 캐릭터가 아니라 STOVE 계정 자체에 코드를 등록하는 방식이라, 게임 안에서 "쿠폰함"을 아무리 찾아도 나오지 않아 처음 하는 사람은 헷갈리기 쉽습니다. 아래에서 두 게임의 등록 순서와 자주 실패하는 이유를 정리했습니다.

STOVE 계정이 왜 필요한가

스마일게이트는 로스트아크, 이클립스: 더 어웨이크닝을 포함한 여러 게임의 계정·쿠폰 시스템을 STOVE라는 통합 플랫폼으로 운영합니다. 쿠폰을 쓰려면 게임 캐릭터가 아니라 STOVE 계정으로 먼저 로그인해야 하고, 그 STOVE 계정이 실제로 플레이 중인 게임 캐릭터와 연결돼 있어야 보상이 들어옵니다. 이 연결 관계를 모르고 다른 계정으로 로그인하면 등록은 되는데 게임 안에서는 보상을 찾을 수 없는 상황이 생깁니다.

로스트아크 쿠폰 등록 방법

  1. 공식 공지나 이벤트 페이지에서 코드를 복사합니다. 대소문자가 섞여 있어 직접 입력하면 오타가 나기 쉽습니다.
  2. 로스트아크 STOVE 쿠폰 등록 페이지로 이동해 평소 플레이하는 캐릭터가 속한 STOVE 계정으로 로그인합니다.
  3. 코드를 붙여 넣고 등록을 누릅니다. 보상은 즉시가 아니라 게임 안 우편함으로 지급되는 경우가 대부분입니다.

코드는 계정당 한 번만 쓸 수 있어서, 등록 후 다른 서버나 캐릭터로 다시 넣어도 중복 지급되지 않습니다. 최신 활성 코드 목록은 로스트아크 쿠폰 코드 모음 글에서, 지금 쓸 수 있는 코드는 로스트아크 쿠폰 페이지에서 확인하는 것이 가장 정확합니다.

이클립스: 더 어웨이크닝 쿠폰 등록 방법

이클립스: 더 어웨이크닝도 같은 STOVE 계정 체계를 쓰지만, 등록 페이지로 가는 경로가 다릅니다. 로스트아크는 전용 쿠폰 등록 페이지가 따로 있는 반면, 이클립스는 공식 홈페이지 고객지원 메뉴 안의 쿠폰 등록 페이지에서 STOVE 계정으로 로그인해 코드를 입력합니다. 절차 자체(복사 → 로그인 → 붙여넣기 → 우편함 확인)는 동일하지만, "쿠폰 등록"만 검색해서는 이 페이지를 바로 찾기 어려우니 고객지원 메뉴를 먼저 확인하는 것이 빠릅니다.

이클립스는 아직 서비스 초기라 신규 코드 발급이 로스트아크보다 뜸한 편입니다. 지금 쓸 수 있는 코드가 있는지는 이클립스: 더 어웨이크닝 쿠폰 페이지에서 바로 확인할 수 있습니다.

등록했는데 안 될 때 확인할 것

증상 가장 흔한 원인
"유효하지 않은 코드"라고 뜬다 코드 앞뒤 공백이나 대소문자 오타. 직접 타이핑 대신 복사·붙여넣기 권장
등록은 됐는데 게임에서 안 보인다 로그인한 STOVE 계정이 실제 플레이 중인 캐릭터와 다른 계정인 경우
우편함에 보상이 없다 우편함이 가득 차 새 우편이 들어오지 않았거나, 아직 게임을 재접속하지 않은 경우
"이미 사용된 코드"라고 뜬다 같은 STOVE 계정으로 이전에 등록했거나 코드 유효기간이 지남

이 네 가지를 확인해도 안 된다면 코드 자체가 만료됐거나 발급 지역이 다를 가능성이 큽니다. 코드마다 유효기간이 다르니 만료 여부는 항상 공식 공지에서 다시 확인하는 것이 정확합니다. 또한 STOVE 로그인 정보를 요구하는 외부 링크가 있다면, 주소가 실제 onstove.com 도메인이 맞는지부터 확인하는 습관이 안전합니다.

자주 묻는 질문

STOVE 계정과 게임 계정이 다른가요?

로스트아크와 이클립스: 더 어웨이크닝은 STOVE 계정으로 로그인해 게임을 시작하는 구조라 별도의 게임 계정을 새로 만들지는 않습니다. 다만 한 STOVE 계정에 여러 캐릭터·서버가 연결될 수 있어, 쿠폰을 등록할 때 로그인한 계정이 실제 플레이하는 캐릭터의 계정이 맞는지 확인하는 것이 중요합니다.

쿠폰을 여러 개 한 번에 등록할 수 있나요?

두 게임 모두 코드를 한 번에 하나씩 등록하는 방식입니다. 여러 코드를 갖고 있다면 순서대로 복사해서 하나씩 붙여 넣어야 하며, 등록 사이에 잠깐의 처리 시간이 걸릴 수 있습니다.

모바일에서도 STOVE 쿠폰 등록이 되나요?

등록 페이지는 웹페이지 형태라 모바일 브라우저에서도 접속과 로그인, 코드 입력이 가능합니다. 다만 보상을 실제로 받으려면 등록 후 PC나 모바일에서 게임을 한 번 실행해 우편함을 확인해야 합니다.

두 게임 모두 절차는 "복사 → STOVE 로그인 → 붙여넣기 → 우편함 확인"으로 같지만, 등록 페이지로 가는 경로와 계정 연결 여부에서 실수가 자주 나옵니다. 코드를 넣기 전에 로그인한 STOVE 계정이 맞는지 한 번만 더 확인하면 대부분의 문제는 피할 수 있습니다.
