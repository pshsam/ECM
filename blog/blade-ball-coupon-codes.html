블레이드 볼 코드 14종 총정리: 입력 위치와 보상 확인법

겜대·ECM 쿠폰 운영자·2026.10.10 작성

블레이드 볼(Blade Ball)은 로블록스에서 서비스되는 PvP 검술 게임으로, 코드는 화면 위쪽 Extra 버튼을 눌러 나오는 Codes 메뉴에 입력합니다. 이 글을 쓰는 시점(2026년 10월) 기준 ECM 쿠폰이 확인한 코드는 14개이고, 대부분 캐릭터 스킨 룰렛을 돌리는 '스핀' 재화를 보상으로 줍니다. 블레이드 볼은 다른 로블록스 게임과 달리 매치를 한 번도 이기지 못하면 Codes 메뉴 버튼 자체가 보이지 않는 독특한 조건이 있어, 코드를 알아도 입력 칸을 못 찾아 헤매는 경우가 많은데 이 부분까지 정리했습니다.

블레이드 볼 코드란

블레이드 볼은 개발사 Wiggity.가 만든 로블록스 PvP 액션 게임으로, 상대가 던진 검을 쳐내는 패링과 반사 신경 싸움이 핵심입니다. 코드는 정해진 발행 주기가 없고, 업데이트나 할로윈·여름 시즌 같은 이벤트에 맞춰 공식 디스코드·X(트위터)에서 예고 없이 공개하는 방식입니다. 보상은 스킨을 뽑는 '스핀' 재화가 가장 많고, 간혹 특정 스킨이나 한정 이벤트 응모권을 직접 주는 코드도 섞여 있습니다.

코드 입력하는 방법

블레이드 볼은 코드 입력 칸으로 가는 길목에 조건이 하나 더 있어서, 순서를 지키지 않으면 "코드가 틀렸다"가 아니라 "입력 칸 자체가 없다"는 상황을 겪게 됩니다.

  1. 지금 쓸 수 있는 코드를 확인합니다. 코드는 블레이드 볼 쿠폰 페이지에서 갱신됩니다.
  2. 매치를 최소 한 번 승리합니다. 블레이드 볼은 1승을 올리기 전에는 Codes 메뉴로 가는 Extra 버튼이 화면에 나타나지 않습니다.
  3. 1승을 올린 뒤 화면 위쪽의 Extra 버튼을 눌러 Codes 메뉴를 엽니다.
  4. 입력 칸에 코드를 그대로 붙여넣고 체크 버튼을 눌러 보상을 받습니다.

신규 유저가 가장 많이 헤매는 지점은 코드 자체보다 이 1승 조건입니다. 로비에서 바로 Extra 버튼을 찾다가 안 보이면 코드나 서버 문제가 아니라, 아직 승리 기록이 없어서인 경우가 대부분입니다.

코드로 받는 보상 종류

코드마다 주는 보상이 다르지만, ECM 쿠폰이 지금까지 모은 코드는 크게 세 갈래로 나뉩니다. 어떤 코드가 정확히 어떤 보상을 주는지는 쿠폰 페이지의 표에서 확인할 수 있습니다.

보상 유형 설명
스핀 캐릭터 스킨을 뽑는 룰렛을 돌리는 재화로, 확인된 14개 코드 중 대부분이 이 보상을 1회씩 줍니다.
전용 스킨 스핀을 거치지 않고 특정 검 스킨을 바로 지급하는 코드가 1개 있습니다.
한정 이벤트·버프 한정 카타나 증정 이벤트의 응모권을 주는 코드, AFK 상태에서 행운을 올려주는 시간제 버프를 주는 코드가 섞여 있습니다.

코드가 안 먹힐 때 체크리스트

  • 1승 조건부터 확인 — Extra 버튼이 안 보인다면 코드 문제가 아니라 아직 승리 기록이 없는 경우입니다. 매치 한 판을 먼저 이겨 보세요.
  • 대소문자 구분 — 로블록스 코드는 대소문자를 구분합니다. 손으로 옮겨 적지 말고 복사해서 붙여넣으세요.
  • 계정당 한 번 — 같은 코드는 한 계정에서 한 번만 적용됩니다. 이미 받은 코드를 다시 넣어도 보상은 또 나오지 않습니다.
  • 예고 없는 종료 — 개발팀이 공지 없이 코드를 닫는 경우가 많아, 위 세 가지를 다 확인했는데도 안 되면 이미 종료된 코드일 가능성이 큽니다.

자주 묻는 질문

Extra 버튼이 아예 안 보여요. 게임이 잘못된 건가요?

아닙니다. 블레이드 볼은 매치를 한 번도 이기지 못한 계정에는 Extra 버튼(Codes 메뉴로 가는 통로)을 보여주지 않습니다. 먼저 아무 매치든 한 판 승리한 뒤 다시 로비 화면을 확인해 보세요.

모바일에서도 입력 방법이 같나요?

네, PC와 모바일 모두 1승 이후 Extra 버튼 → Codes 메뉴 → 입력 칸의 순서가 같습니다. 모바일은 화면이 작아 Extra 버튼이 다른 아이콘 사이에 작게 보이니 화면 위쪽을 잘 살펴보세요.

코드로 받은 스핀은 어디에 쓰나요?

스핀은 캐릭터 검 스킨을 뽑는 룰렛을 돌리는 데 씁니다. 외형에만 영향을 주고 전투 능력치는 바꾸지 않으므로, 쌓아두기보다는 모이는 대로 돌려서 스킨을 확인해 보는 편이 낫습니다.

블레이드 볼 코드는 입력 위치보다 1승 조건을 모르면 더 헤매는 구조입니다. 다른 로블록스 게임은 코드 입력 위치가 제각각이라 헷갈리기 쉬운데, 로블록스 코드 입력 위치 총정리에서 게임별 버튼 위치를 함께 확인할 수 있습니다. 로블록스 외 게임의 코드 운영 방식이 궁금하다면 게임 쿠폰 완벽 가이드도 참고하세요.
