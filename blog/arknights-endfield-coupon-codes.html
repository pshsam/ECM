2026년 1월 정식 출시된 「명일방주: 엔드필드」는 원작 명일방주의 세계관을 오픈월드 액션 RPG로 확장한 작품으로, 출시 이후 지금도 라이브 방송과 업데이트 시점마다 리딤코드가 꾸준히 공개되고 있습니다. 이 글에서는 엔드필드 쿠폰(리딤코드)의 개념부터 최신 코드 목록, 플랫폼별 정확한 입력 방법, 자주 하는 실수까지 한 번에 정리했습니다.

명일방주 엔드필드 쿠폰이란?

엔드필드 쿠폰은 개발사 하이퍼그린(Hypergryph)이 라이브 방송, 신규 버전 업데이트, 서버 점검 보상 등의 명목으로 배포하는 교환 코드입니다. 코드를 입력하면 탈로시안 화폐, 오로베릴, 육성 아이템 등의 보상을 즉시 받을 수 있습니다.

  • 탈로시안 화폐: 상점 재화 및 각종 소모품 구매에 사용
  • 오로베릴: 캐릭터 소환(가챠)에 사용되는 핵심 재화
  • 육성 아이템: 캐릭터 레벨업·강화용 소재

쿠폰 코드 입력 방법 (플랫폼별)

PC/모바일 게임 내에서 입력

  1. 게임 실행 후 좌측 메뉴의 우편함(봉투) 아이콘 클릭
  2. 하단 "코드 교환" 또는 "리딤코드" 버튼 클릭
  3. 코드 입력 후 "교환하기" 클릭
  4. 우편함에서 보상 수령

PC 전용 코드 주의사항

일부 코드(예: ENDFIELD4PC)는 PC 클라이언트에서만 입력이 가능합니다. 모바일에서 입력이 되지 않는다면 코드 자체가 PC 전용인지 먼저 확인하세요.

계정 연동 확인

PC와 모바일을 함께 플레이한다면 동일 계정으로 로그인되어 있는지 확인 후 코드를 입력해야 보상이 정상적으로 지급됩니다.

코드가 자주 나오는 시점

엔드필드 코드는 대체로 신규 버전 업데이트 발표 방송, 서버 점검 보상, 대형 이벤트 시작 시점에 맞춰 공개됩니다. 업데이트 프리뷰 방송 직후가 가장 신규 코드가 나올 확률이 높은 타이밍입니다.

자주 하는 실수

  • 공백 포함 복사: 코드 앞뒤 공백이 포함되면 오류가 납니다. 복사 후 직접 확인하세요.
  • 대소문자 혼동: 일부 코드는 대소문자를 구분합니다. 그대로 복사하는 게 안전합니다.
  • 플랫폼 오선택: PC 전용 코드를 모바일에서 입력하면 오류가 발생합니다.
  • 만료 후 시도: 라이브 방송 한정 코드는 대부분 짧은 시간 내 만료됩니다.
