화이트아웃 서바이벌 기프트 코드란

화이트아웃 서바이벌은 센추리게임즈(Century Games)가 서비스하는 빙하기 배경의 생존·전략 게임으로, 기지 건설과 동맹 전투를 함께 즐기는 모바일 SLG입니다. 게임사는 업데이트나 기념일마다 보석·가속 아이템·자원 같은 보상을 주는 기프트 코드를 공개하는데, 코드는 정해진 주기 없이 공식 채널을 통해 나옵니다. 아래 표는 코드 등록에 필요한 기본 정보입니다.

기프트 코드 센터에서 등록하는 방법

입력 페이지가 게임 안에 있지 않고 별도 웹사이트로 분리돼 있어, 처음에는 어디서 코드를 넣어야 하는지 헷갈릴 수 있습니다. 순서는 다음과 같습니다.

  1. 게임을 실행해 화면 왼쪽 위 아바타를 눌러 플레이어 ID를 확인하고 복사합니다.
  2. 브라우저로 공식 기프트 코드 센터(wos-giftcode.centurygame.com)에 접속합니다.
  3. 플레이어 ID를 입력해 로그인한 뒤, 코드를 붙여 넣고 등록 버튼을 누릅니다. 보상은 게임 내 우편함으로 지급됩니다.

계정과 게임 데이터가 같은 서버에 있다면 기기를 바꿔도 같은 방법으로 등록할 수 있습니다. 코드마다 유효기간이 다르므로, 등록 전 화면에 뜨는 안내 문구로 만료 여부를 한 번 더 확인하는 것이 좋습니다.

코드가 풀리는 경로와 미리 챙기는 법

화이트아웃 서바이벌 코드는 공식 X(트위터)·페이스북·디스코드 공지, 그리고 게임 내 대규모 업데이트나 다운로드 수 기념 이벤트 때 함께 공개되는 경우가 많습니다. 유튜버·스트리머와 연계한 한정 코드가 올라오기도 합니다. 커뮤니티에 떠도는 코드는 이미 만료됐거나 확인되지 않은 것이 섞여 있으니, 날짜가 명시된 공식 공지나 검증된 정리 페이지에서 다시 확인하는 편이 안전합니다.

코드가 안 먹힐 때 확인할 점

  • 대소문자와 앞뒤 공백을 확인하세요. 코드 대부분이 영문·숫자 조합이라 옮겨 적을 때 오탈자가 나기 쉽습니다.
  • 코드는 보통 계정당 한 번만 사용됩니다. 이미 등록한 코드를 다시 넣으면 오류가 뜹니다.
  • 플레이어 ID를 잘못 입력하면 다른 계정으로 코드가 등록될 수 있으니, 아바타 화면의 ID와 일치하는지 다시 확인하세요.
  • 정확히 입력했는데도 안 된다면 코드 유효기간이 지났을 가능성이 큽니다. 같은 코드라도 국가·서버별로 적용 여부가 다를 수 있습니다.

같은 개발사 킹샷과 등록 방식 비교

센추리게임즈는 킹샷(Kingshot)이라는 또 다른 생존 SLG도 서비스하고 있는데, 두 게임의 코드 등록 방식이 거의 똑같습니다. 둘 다 게임 밖 웹 기프트 코드 센터에서 플레이어 ID로 로그인해 코드를 넣는 구조라, 한 게임에서 방법을 익히면 다른 게임에서도 헤매지 않습니다. 다만 코드 자체는 게임별로 따로 발급되므로 서로 바꿔 쓸 수는 없습니다.
