나 혼자만 레벨업: 어라이즈 쿠폰, 어디서 나오나

나 혼자만 레벨업: 어라이즈는 동명의 웹소설·웹툰을 원작으로 한 넷마블의 액션RPG로, 플레이어는 '헌터' 역할을 맡아 주인공 성진우와 함께 던전을 돌파합니다. 넷마블 게임은 보통 코드를 특정 요일에 정기적으로 내지 않고, 공식 카페 공지나 쇼케이스·업데이트 방송, 출시·기념일 이벤트에 맞춰 발표합니다. 사전등록이나 출시 초반에는 '웰컴 쿠폰' 형태로 묶어서 내는 경우도 많습니다. ECM 쿠폰은 게임사 공식 채널과 독립된 출처 두 곳에서 교차로 확인된 코드만 쿠폰 페이지에 올리기 때문에, 커뮤니티에 떠도는 코드 중 출처가 불분명한 것은 올리지 않습니다.

코드 입력 방법 두 가지

쿠폰 페이지에서 코드를 확인했다면 아래 두 방법 중 편한 쪽 하나만 쓰면 됩니다. 둘 다 시도할 필요는 없으며, 한 번 등록된 코드는 다른 경로로 다시 넣어도 '이미 사용된 코드'로 처리됩니다.

  1. 게임 안에서: 게임을 실행한 뒤 설정(톱니바퀴) 메뉴로 들어가 Redeem Code 항목에 코드를 입력합니다.
  2. 웹에서: 넷마블 쿠폰 등록 페이지(coupon.netmarble.com/sololv)에 접속해 계정으로 로그인한 뒤 코드를 입력합니다. 게임을 켜지 않은 상태에서도 등록할 수 있습니다.

계정 연동이나 넷마블 쿠폰 등록 자체가 처음이라 헷갈린다면 넷마블 쿠폰 등록 방법 가이드에서 게임별 차이와 절차를 더 자세히 설명하니 함께 참고하면 좋습니다.

입력했는데 안 될 때 자주 틀리는 점

증상 확인할 점
'이미 사용된 코드' 게임 안과 웹 양쪽에 같은 코드를 넣어본 경우 흔히 뜹니다. 코드는 계정당 한 번만 인정되니 한쪽에서만 입력하세요.
'유효하지 않은 코드' 대소문자나 공백이 섞여 들어가는 경우가 많습니다. 손으로 옮기지 말고 쿠폰 페이지에서 복사해 붙여넣으세요.
다른 사이트에서 본 코드가 안 됨 등록일 표시가 없는 커뮤니티 글의 코드는 만료됐거나 확인되지 않은 것이 섞여 있습니다. 등록일이 적힌 출처에서 다시 확인하세요.
등록은 됐는데 보상이 안 보임 즉시 지급이 아니라 게임 안 우편함으로 들어옵니다. 게임을 재접속해 우편함을 확인하세요.

코드 자체는 맞는데 계속 안 된다면, 사용 기한이 지났거나 지역이 다른 서비스의 코드일 가능성도 있습니다. 좀 더 다양한 상황을 점검하고 싶다면 쿠폰 코드가 안 될 때 확인할 5가지도 참고하세요.

코드로 받을 수 있는 보상 종류

코드마다 구성은 다르지만, 대체로 아래 갈래 안에서 조합됩니다. 정확한 수량은 코드마다 달라 외워둘 필요는 없고, 등록 직후 게임 안 우편함에서 확인하는 편이 정확합니다.

  • 성장 재화 — 헌터와 장비를 키우는 데 쓰는 강화 재료 종류입니다.
  • 프리미엄 재화 — 상점이나 모집(가챠)에 쓸 수 있는 유상 화폐 성격의 재화입니다.
  • 골드·소모품 — 강화·수리 등 기본 플레이에 바로 쓰는 재화와 물약류입니다.

자주 묻는 질문

게임 안과 웹, 둘 다 입력해야 하나요?

아닙니다. 둘 중 한 곳에서만 입력하면 됩니다. 같은 코드를 양쪽에 넣으면 두 번째 시도는 '이미 사용된 코드'로 처리됩니다.

지금 쓸 수 있는 코드가 없는데, 언제 다시 나오나요?

정해진 날짜는 없습니다. 보통 업데이트나 쇼케이스, 기념일 이벤트에 맞춰 발표되므로, 쿠폰 페이지를 즐겨찾기 해두고 공식 공지가 뜰 때 다시 확인하는 쪽이 가장 확실합니다.

코드 보상은 어디서 받나요?

게임 안과 웹 어느 경로로 입력하든 보상은 게임 안 우편함으로 지급됩니다. 등록 후 보상이 안 보이면 게임을 재접속해 우편함부터 확인하세요.

나 혼자만 레벨업: 어라이즈 쿠폰은 게임 안 설정 메뉴와 웹 등록 페이지 중 한 곳에서만 입력하면 되는 대신, 발표 시점을 예측하기 어려운 편입니다. 코드가 안 먹힐 때는 중복 입력, 오타, 출처 불분명한 코드 순서로 확인해보면 대부분 원인을 찾을 수 있습니다. 새 코드가 확인되는 대로 쿠폰 페이지에 바로 반영되니, 플레이 전에 한 번씩 들러 확인하는 습관을 들이면 좋습니다.
