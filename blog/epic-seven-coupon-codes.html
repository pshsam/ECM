에픽세븐 쿠폰 코드 총정리: 최신 코드와 스토브 등록 방법

겜대·ECM 쿠폰 운영자·2026.09.25 작성

에픽세븐 쿠폰 코드는 게임 안 이벤트 탭이나 스마일게이트의 공식 플랫폼인 STOVE 쿠폰 페이지에서 입력합니다. 계정에 STOVE 로그인이 연결돼 있어야 하고, 코드 하나는 계정당 한 번만 쓸 수 있습니다. 코드 자체는 자주 바뀌기 때문에 이 글에서는 외우지 않아도 되게, 입력 절차와 자주 실패하는 이유를 먼저 정리했습니다. 지금 쓸 수 있는 코드는 에픽세븐 쿠폰 페이지에서 확인하세요.

에픽세븐 쿠폰, 어디서 나오나

에픽세븐은 스마일게이트 메가포트가 서비스하는 수집형 턴제RPG로, PC와 모바일을 넘나드는 크로스플랫폼을 지원합니다. 쿠폰 코드는 정해진 요일 없이 공식 커뮤니티 공지나 로스트아크 등 다른 자사 타이틀과 함께 진행하는 라이브 방송(로아온 등)에서 발표되는 경우가 많습니다. 대규모 업데이트나 신규 영웅 출시 시점에 몰아서 나오는 편이라, 평소보다 공지가 잦아지면 코드가 풀릴 확률도 높다고 보면 됩니다. ECM 쿠폰은 공식 채널과 별도 커뮤니티 출처 두 곳에서 교차로 확인한 코드만 쿠폰 페이지 표에 올립니다.

쿠폰 코드 입력 방법

스마일게이트 게임은 게임 내 쿠폰 입력창이 따로 없고, STOVE 계정으로 로그인한 뒤 웹에서 입력하는 방식을 씁니다. 스토브 계정 자체를 처음 만드는 경우라면 스토브 쿠폰 등록 방법 가이드를 먼저 보고 오면 헷갈리지 않습니다.

  1. 에픽세븐 쿠폰 페이지에서 지금 살아있는 코드를 복사합니다.
  2. STOVE 에픽세븐 쿠폰 페이지(epic7.onstove.com/ko/coupon)에 접속해 로그인합니다.
  3. 서버와 캐릭터 닉네임을 선택합니다.
  4. 코드 입력란에 붙여넣고 확인을 누르면, 보상은 게임 안 우편함으로 도착합니다.

입력했는데 안 될 때 확인할 점

증상 점검할 점
'유효하지 않은 코드' 대문자·숫자를 손으로 옮기다 오타가 나는 경우가 많습니다. 복사·붙여넣기로 다시 시도하세요.
'이미 사용된 코드' 계정당 1회만 인정됩니다. 같은 코드를 다른 캐릭터에 다시 넣어도 적용되지 않습니다.
서버 선택 후에도 실패 해당 코드가 특정 서버·지역 한정으로 배포된 경우입니다. 쿠폰 페이지의 대상 범위를 다시 확인하세요.
보상이 안 옴 즉시 지급이 아니라 게임 안 우편함으로 오는 경우가 대부분입니다. 게임을 재접속해 우편함을 확인하세요.

코드로 받는 보상

보상 구성은 코드마다 다르지만, 대체로 아래 세 갈래 안에서 조합됩니다. 정확한 수량은 매번 바뀌므로 쿠폰 페이지 표에서 코드별로 확인하는 편이 정확합니다.

  • 성장 재화 — 전승석, 강화석처럼 영웅을 키우는 데 쓰는 기본 재화입니다.
  • 골드 — 장비 강화나 상점 구매에 바로 쓸 수 있는 게임 화폐입니다.
  • 선택 상자 — 여러 아이템 중 원하는 것을 직접 고를 수 있어 다른 보상보다 체감 가치가 높습니다.

코드를 놓치지 않으려면

에픽세븐은 코드가 나오는 날짜가 정해져 있지 않아, 공지를 챙겨보지 않으면 만료 기간(보통 발표 후 몇 주 안팎) 안에 놓치기 쉽습니다. 공식 커뮤니티를 매번 들어가 확인하기 번거롭다면, ECM 쿠폰의 에픽세븐 쿠폰 페이지를 북마크해두고 새 코드가 뜰 때 NEW 표시로 확인하는 방법이 더 간단합니다.

자주 묻는 질문

에픽세븐 쿠폰은 어디서 입력하나요?

게임 내 입력창은 없고, STOVE 계정으로 로그인한 뒤 웹의 에픽세븐 쿠폰 페이지(epic7.onstove.com/ko/coupon)에서 서버·닉네임을 선택해 입력합니다.

쿠폰 코드는 몇 번까지 쓸 수 있나요?

코드 하나당 계정 1회만 인정됩니다. 여러 캐릭터를 굴려도 같은 코드를 두 번 넣을 수는 없습니다.

STOVE 계정이 없으면 어떻게 하나요?

먼저 STOVE 계정을 만들고 게임과 연동해야 쿠폰을 쓸 수 있습니다. 계정 생성부터 연동까지는 스토브 쿠폰 등록 방법 가이드에서 단계별로 안내합니다.

에픽세븐 쿠폰은 발표 시점을 예측하기 어려운 대신, 발표되면 STOVE 계정 로그인만으로 빠르게 받을 수 있는 편입니다. 코드가 안 먹힐 때는 오타나 중복 사용, 서버 한정 여부부터 순서대로 짚어보세요. 최신 코드는 계속 갱신되니, 새 코드가 나왔는지는 게임을 켜기 전에 쿠폰 페이지에서 한 번 확인하는 습관을 들이면 좋습니다.
