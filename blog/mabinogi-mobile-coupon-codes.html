마비노기 모바일 쿠폰 코드 총정리와 넥슨 모바일 쿠폰 등록 방법

겜대·ECM 쿠폰 운영자·2026.09.30 작성

마비노기 모바일 쿠폰 코드는 게임 안이 아니라 넥슨 모바일 쿠폰 페이지(mcoupon.nexon.com)에서 넥슨ID로 로그인해 입력합니다. PC와 모바일을 오가며 즐기는 크로스플랫폼 게임이라 어느 기기에서 코드를 넣어도 같은 넥슨 계정이면 보상은 한 번만 지급됩니다. 이 글에서는 마비노기 모바일 쿠폰 코드 페이지에서 확인할 수 있는 등록 방법과 보상 수령 방식, 코드가 안 먹힐 때 흔히 놓치는 점을 정리했습니다.

쿠폰은 어디서, 어떤 방식으로 입력하나

마비노기 모바일은 다른 넥슨 게임처럼 게임 내 쿠폰함이 아니라 웹 페이지인 넥슨 모바일 쿠폰(mcoupon.nexon.com/mabinogimobile)에서 코드를 등록합니다. 접속 후 넥슨ID로 로그인하고, 코드를 붙여 넣은 다음 확인을 누르면 됩니다. 대표 캐릭터를 따로 지정하는 절차는 없고, 계정에 연결된 캐릭터가 있다면 그쪽으로 보상이 들어갑니다.

코드는 대문자 영문·숫자 조합이 많고, 손으로 옮겨 적다 보면 대소문자나 숫자 0과 알파벳 O를 헷갈리기 쉽습니다. 코드를 보는 화면에서 그대로 복사해 붙여 넣는 것이 가장 안전합니다.

크로스플랫폼이라 헷갈리는 점

마비노기 모바일은 PC와 모바일 양쪽에서 즐길 수 있는 크로스플랫폼 게임입니다. 그래서 "모바일로 받은 코드를 PC에서도 따로 넣어야 하나" 궁금해하는 경우가 많은데, 쿠폰은 게임 버전이 아니라 넥슨 계정 단위로 지급되므로 한 번만 등록하면 됩니다. 반대로 같은 코드를 다른 캐릭터나 다시 로그인해 재입력해도 이미 사용한 코드로 처리되어 보상은 추가로 나오지 않습니다.

원작 마비노기 PC와는 별도 게임

같은 세계관을 쓰지만 마비노기 모바일은 원작 PC판 마비노기와는 별도로 서비스되는 게임입니다. 계정·캐릭터가 서로 연동되지 않기 때문에 쿠폰 역시 호환되지 않습니다. 원작 마비노기 코드를 마비노기 모바일 쿠폰 페이지에 넣거나, 반대로 마비노기 모바일 코드를 원작 게임 쪽에 넣어도 인식되지 않으니 검색할 때 게임 이름을 정확히 구분하는 것이 좋습니다.

보상은 어떻게, 언제 받나

코드를 등록하면 보상은 보통 게임 안 우편함으로 도착합니다. 우편함 보관 기간이 지나면 수령하지 못할 수 있으니, 코드를 넣은 뒤에는 접속해서 우편함을 바로 확인하는 습관을 들이는 편이 좋습니다.

마비노기 모바일에는 다른 넥슨 게임에 없는 기능이 하나 있는데, 휴대폰 인증이나 넥슨ID 로그인을 하면 사전예약·이벤트로 이미 발급된 내 쿠폰 번호를 웹 페이지에서 직접 조회할 수 있습니다. 참여했던 이벤트의 쿠폰 번호를 저장해두지 않아 잊어버렸다면, 새로 코드를 찾아다니기 전에 이 조회 기능부터 확인하는 것이 빠릅니다.
