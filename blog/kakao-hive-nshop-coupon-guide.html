겜대·ECM 쿠폰 운영자·2026.09.29 작성

오딘: 발할라 라이징, 제우스: 오만의 신, 아이온2, 리니지M은 코드를 넣는 사이트가 각각 다릅니다. 오딘은 카카오게임즈 쿠폰 페이지, 제우스는 하이브(Hive), 아이온2와 리니지M은 엔씨소프트의 NShop을 씁니다. 다른 게임에서 하던 대로 검색하면 엉뚱한 사이트로 가기 쉬워 헷갈린다는 문의가 많습니다. 네 게임의 등록 주소와 절차를 한 번에 정리했습니다.

왜 게임마다 등록 사이트가 다를까

쿠폰 등록 사이트는 게임을 만든 회사가 아니라 계정·결제를 관리하는 퍼블리셔 플랫폼을 따라갑니다. 오딘은 카카오게임즈가 서비스하는 게임이라 카카오게임즈 자체 쿠폰 페이지(coupon.kakaogames.com)를 씁니다. 제우스는 컴투스가 만든 게임이라 컴투스 계열 통합 플랫폼인 하이브(Hive)로 등록합니다. 아이온2와 리니지M은 둘 다 엔씨소프트 게임이라 NC의 통합 상점 NShop(nshop.plaync.com)에서 코드를 넣습니다. 즉 게임사가 같으면 등록 사이트도 같습니다.

오딘: 발할라 라이징 쿠폰 등록 방법 (카카오게임즈)

오딘 쿠폰은 카카오게임즈 쿠폰 등록 페이지에서 넣거나, 게임 안에서 설정 > 계정 > 쿠폰 등록으로 들어가도 됩니다. 코드를 복사해 붙여 넣고 확인을 누르면 보상이 우편함으로 옵니다. 지금 쓸 수 있는 코드는 오딘: 발할라 라이징 쿠폰 페이지에서 확인하세요.

제우스: 오만의 신 쿠폰 등록 방법 (하이브)

제우스 쿠폰은 공식 홈페이지 또는 하이브(Hive) 쿠폰 등록 페이지에서 넣습니다. 하이브는 컴투스 계열 게임 여러 개가 같이 쓰는 통합 계정 시스템이라, 이미 하이브 계정이 있으면 별도 가입 없이 로그인만 하면 됩니다. 코드를 붙여 넣고 확인을 누르면 게임 우편함으로 보상이 도착합니다. 지금 쓸 수 있는 코드는 제우스 쿠폰 페이지에서 확인할 수 있습니다.

아이온2·리니지M 쿠폰 등록 방법 (NC NShop)

아이온2

아이온2는 NC 공식 쿠폰 등록 페이지(NShop) 또는 게임 안 설정 > 기타 > 쿠폰 등록에서 코드를 넣습니다. 코드는 계정당 한 번만 쓸 수 있어 다른 캐릭터로 다시 넣어도 중복 지급되지 않습니다. 지금 쓸 수 있는 코드는 아이온2 쿠폰 페이지에서 확인하세요.

리니지M

리니지M은 같은 NShop을 쓰지만 등록 전에 서버를 먼저 선택해야 합니다. 서버를 잘못 고르면 코드를 넣어도 실제로 캐릭터가 있는 서버에 보상이 들어오지 않으니 주의가 필요합니다. 코드는 유형별로 계정당 한 번만 인정됩니다. 최신 코드는 리니지M 쿠폰 페이지에서 확인할 수 있습니다.

공통으로 우편함을 미리 비워 두는 것이 중요합니다. 우편함이 가득 차 있으면 코드는 정상 처리돼도 보상을 받지 못하는 경우가 있습니다. 또한 네 게임 모두 코드는 계정당 한 번만 인정되므로, 다른 서버나 캐릭터로 같은 코드를 다시 넣어도 추가 보상은 없습니다.

자주 묻는 질문

하이브 계정과 카카오게임즈 계정은 같은 건가요?

아닙니다. 하이브는 컴투스 계열 게임(제우스 등)이 쓰는 통합 계정이고, 카카오게임즈 쿠폰 페이지는 카카오게임즈가 서비스하는 게임(오딘 등) 전용입니다. 서로 다른 회사의 서로 다른 시스템이라 계정을 공유하지 않습니다.

아이온2 코드를 리니지M에도 쓸 수 있나요?

둘 다 NShop을 쓰지만 코드는 게임별로 따로 발급되고 등록 페이지에서 게임을 선택해서 넣기 때문에 다른 게임의 코드를 대신 쓸 수는 없습니다.

등록했는데 보상이 안 왔어요.

가장 흔한 원인은 우편함이 가득 찬 경우와, 리니지M처럼 서버 선택이 필요한 게임에서 실제 캐릭터가 있는 서버와 다른 서버를 고른 경우입니다. 그다음으로는 코드를 이미 같은 계정으로 한 번 사용한 경우입니다. 확인 후에도 안 되면 각 게임의 공식 고객센터에 문의하는 것이 정확합니다.

등록 사이트만 헷갈리지 않으면 절차 자체는 네 게임 모두 복사, 붙여넣기, 확인으로 단순합니다. ECM 쿠폰은 각 게임 페이지에서 확인된 코드만 정리해 올리니, 코드를 찾을 때는 위에 연결한 게임별 쿠폰 페이지를 즐겨찾기해 두는 것을 권합니다.
