검은사막 모바일 코드 6종 총정리: 입력 방법과 보상 확인법

겜대·ECM 쿠폰 운영자·2026.10.11 작성

검은사막 모바일(Black Desert Mobile)은 코드를 게임 안이 아니라 공식 홈페이지의 별도 쿠폰 페이지에서 입력합니다. ECM 쿠폰이 2026년 10월 기준으로 확인한 코드는 6개이며, 모두 10월 27일까지 쓸 수 있습니다. 입력 칸에는 캐릭터명이 아니라 '가문명'을 넣어야 하는데, 이 부분에서 실패하는 경우가 적지 않습니다. 이 글에서는 입력 방법부터 코드별 보상 성격, 가문명 입력 때 자주 틀리는 점까지 정리했습니다.

검은사막 모바일은 어떤 게임인가

검은사막 모바일은 펄어비스가 개발·서비스하는 모바일 MMORPG로, PC판 검은사막과 세계관과 지역 이름을 공유하지만 조작과 성장 구조는 모바일 환경에 맞게 따로 만들어졌습니다. PC판처럼 '가문' 단위로 계정을 관리하기 때문에 쿠폰도 캐릭터가 아니라 가문 쪽으로 지급됩니다. PC판 검은사막의 코드는 따로 운영되므로, PC 이용자라면 검은사막 PC 쿠폰 코드 글을 참고하는 편이 맞습니다.

코드 입력하는 방법

검은사막 모바일은 인게임 메뉴에 코드 입력 칸이 없고, 공식 쿠폰 등록 페이지를 따로 열어야 합니다.

  1. 공식 쿠폰 등록 페이지(game.blackdesertm.com/coupon)에 접속합니다.
  2. 캐릭터명이 아니라 가문명을 입력합니다.
  3. 코드를 복사해 붙여넣습니다.
  4. 등록 버튼을 눌러 신청을 완료합니다. 보상은 즉시 지급되지 않고 인게임 우편함으로 들어옵니다.

지금 쓸 수 있는 코드는 검은사막 모바일 쿠폰 페이지에서 확인할 수 있습니다.

코드로 받는 보상 종류

ECM 쿠폰이 확인한 6개 코드는 보상 성격에 따라 크게 네 갈래로 나뉩니다. 코드 하나에 재화 여러 종류가 묶여 나오는 경우가 많아, 아래 표는 코드별이 아니라 보상 유형별로 정리했습니다.

보상 유형 설명
강화·성장 재료 돌파 복구권, 기술 비전 파편, 태양의 결정처럼 장비 강화나 캐릭터 성장에 바로 쓰는 재료입니다. 6개 코드 중 가장 많은 수가 이 유형에 속합니다.
프리미엄 재화 블랙펄처럼 유료 상점에서 쓰는 재화를 소량 지급하는 코드입니다. 지급량이 크지 않아 보조용으로 보는 편이 맞습니다.
선택형 상자 정제수·유자차·시계 태엽처럼 여러 재료 중 하나를 고르는 선택 상자입니다. 어떤 항목을 고르느냐에 따라 활용도가 달라집니다.
입장권·편의 아이템 협동 레이드나 흑정령 사당 같은 콘텐츠 입장권, 클래스 변경 상자처럼 플레이 편의를 돕는 보상입니다.

6개 코드 모두 2026년 10월 27일 만료로 등록되어 있어, 이 날짜가 지나면 입력해도 적용되지 않습니다. 코드별 정확한 보상 목록과 잔여 기간은 검은사막 모바일 쿠폰 페이지에서 확인하세요.

코드가 안 먹힐 때 체크리스트

  • 가문명과 캐릭터명 구분 — 등록 페이지는 캐릭터명이 아니라 가문명을 요구합니다. 캐릭터명을 넣으면 가문을 찾지 못해 등록 자체가 실패합니다.
  • 만료일 확인 — 지금 안내하는 6개 코드는 10월 27일까지만 유효합니다. 그 이후에는 새 코드로 교체됩니다.
  • 계정당 1회 — 같은 코드를 같은 가문에 두 번 등록할 수 없습니다. 이미 받은 코드는 재입력해도 추가 지급되지 않습니다.
  • 우편함 확인 지연 — 등록이 완료돼도 인게임 우편함 반영까지 시간이 걸릴 수 있어, 바로 안 보이면 게임을 재접속해 다시 확인하는 편이 좋습니다.

자주 묻는 질문

가문명이 뭔가요? 캐릭터명과 뭐가 다른가요?

가문명은 계정 전체를 대표하는 이름이고, 캐릭터명은 그 가문 아래 만든 개별 캐릭터의 이름입니다. 쿠폰 보상은 가문 단위로 지급되기 때문에 등록 페이지에는 캐릭터명이 아니라 가문명을 입력해야 합니다.

코드를 등록했는데 우편함에 안 보여요.

등록 직후에는 서버 반영이 늦어 바로 보이지 않을 수 있습니다. 게임을 재접속해 우편함을 다시 확인하고, 그래도 안 보이면 가문명을 정확히 입력했는지와 코드 만료일을 다시 확인하세요.

검은사막 모바일 코드는 얼마나 자주 나오나요?

정해진 발행 주기는 공식적으로 밝혀진 적이 없습니다. 지금까지 확인된 코드들은 개발자 코멘터리 공개나 설문 참여 감사처럼 특정 행사·공지에 맞춰 나오는 경우가 많아, 공식 공지가 뜰 때마다 검은사막 모바일 쿠폰 페이지에서 갱신 여부를 확인하는 편이 가장 확실합니다.
