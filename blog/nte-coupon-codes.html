이환(Neverness to Everness) 쿠폰 코드 총정리와 입력 방법

겜대·ECM 쿠폰 운영자·2026.09.24 작성·2026.09.25 수정

이환(Neverness to Everness) 쿠폰 코드는 게임 안에서 화면 우측 상단 메뉴의 '교환 코드(Redemption Code)' 항목을 눌러 입력합니다. 코드를 넣으면 성장에 쓰는 재화나 초반 아이템을 우편함으로 받을 수 있는데, 코드는 게임사가 공지 없이 닫아버리는 경우가 많아 이 글만으로는 지금 살아있는 코드까지 알기는 어렵습니다. 실시간으로 확인된 코드는 이환 쿠폰 페이지에서 따로 갱신하고 있으니, 여기서는 입력 방법과 보상 종류, 코드가 안 먹힐 때 점검할 것들을 정리했습니다.

이환(Neverness to Everness)이란

이환은 퍼펙트월드게임즈가 서비스하는 오픈월드 액션RPG로, PC와 PS5, 모바일을 크로스플랫폼으로 지원합니다. 같은 계정이면 어느 기기에서 접속하든 진행 상황이 이어지고, 쿠폰 코드도 계정 단위로 한 번만 인정됩니다. 국내에는 비교적 최근 알려지기 시작한 타이틀이라 코드 관련 정보를 정리한 글이 아직 많지 않은데, 그만큼 처음 검색해서 들어온 분들이 입력 위치부터 헤매는 경우가 많습니다.

쿠폰 코드 입력 방법

입력 위치만 알면 절차는 어렵지 않습니다. 다만 한 글자라도 다르게 입력하면 실패로 처리되니 손으로 옮겨 적기보다 복사·붙여넣기를 권합니다.

  1. 지금 사용 가능한 코드를 이환 쿠폰 페이지에서 확인하고 복사합니다.
  2. 게임에 접속해 화면 우측 상단 메뉴를 엽니다.
  3. '교환 코드(Redemption Code)' 항목을 찾아 들어갑니다.
  4. 입력 칸에 붙여넣고 확인을 누르면, 보상은 대부분 게임 안 우편함으로 도착합니다.

코드로 받을 수 있는 보상 종류

이환의 쿠폰 보상은 크게 세 갈래로 나뉩니다. 어떤 코드가 어떤 보상을 주는지는 시기마다 달라지므로, 정확한 항목은 쿠폰 페이지의 표에서 확인하는 게 가장 빠릅니다.

보상 유형 설명
성장 재화 캐릭터 강화나 장비 제작에 쓰는 기본 재화입니다. 초반 진행 속도를 앞당기는 데 가장 흔히 쓰입니다.
외형 아이템 염료 같은 커스터마이징 소재로, 전투력과는 무관하고 캐릭터 외형을 꾸미는 데 씁니다.
이벤트 전용 아이템 특정 시즌이나 콜라보에 맞춰 한시적으로 풀리는 아이템으로, 재획득이 어려운 경우가 많습니다.

코드가 안 먹힐 때 확인할 점

  • 대소문자·공백 — 영문과 숫자가 섞인 코드는 대소문자를 구분하는 경우가 있습니다. 직접 입력했다면 복사·붙여넣기로 다시 시도해 보세요.
  • 계정당 한 번 — 같은 코드는 계정마다 한 번만 인정됩니다. 다른 캐릭터로 다시 넣어도 중복 지급되지 않습니다.
  • 우편함 확인 — 보상이 안 보이면 우편함이 가득 차 있는지 먼저 확인하세요. 자리가 없으면 지급이 안 되거나 늦어질 수 있습니다.
  • 이미 만료된 코드 — "상시 유효"로 안내된 코드도 게임사가 예고 없이 닫는 경우가 있습니다. 철자를 다 확인했는데도 안 된다면 만료됐을 가능성이 큽니다.

새 코드는 정해진 주기 없이 업데이트나 공식 방송, 콜라보 이벤트 때 공개됩니다. 정확한 시점은 게임사 공식 채널에서 예고하므로, 커뮤니티나 출처가 불분명한 영상에서 "미공개 코드"를 안다며 계정 정보를 요구하면 가짜 쿠폰 사이트 구별법을 참고해 거르는 게 안전합니다. 다른 게임까지 포함한 코드 관리 요령은 게임 쿠폰 완벽 가이드에서도 확인할 수 있습니다.

자주 묻는 질문

이환 쿠폰 코드는 어디서 입력하나요?

게임 접속 후 화면 우측 상단 메뉴에서 '교환 코드(Redemption Code)' 항목을 찾아 들어가면 입력 칸이 나옵니다.

PC에서 받은 보상을 모바일에서도 쓸 수 있나요?

같은 계정으로 로그인했다면 가능합니다. 이환은 PC·PS5·모바일을 크로스플랫폼으로 지원해 계정 기준으로 진행과 보상이 공유됩니다.

지금 쓸 수 있는 코드는 어디서 확인하나요?

코드는 예고 없이 열리고 닫히기 때문에 이 글보다는 이환 쿠폰 페이지처럼 주기적으로 갱신되는 곳에서 확인하는 게 정확합니다.

이환은 아직 국내에 코드 정보가 많이 정리되지 않은 게임이라, 입력 위치와 계정당 한 번이라는 기본 규칙만 알아두면 헤맬 일이 줄어듭니다. 코드 자체는 수시로 바뀌니 확인된 목록을 즐겨찾기해두고 그때그때 챙기는 편이 가장 확실합니다.
