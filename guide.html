사용 방법

코드 넣기

  1. 홈이나 게임 쿠폰 목록에서 게임을 고르세요.
  2. 코드 옆 복사를 누르세요. 대소문자까지 그대로 복사돼요.
  3. 게임 페이지의 입력하는 곳 안내대로 게임 안 쿠폰 메뉴나 공식 입력 페이지를 열어 붙여 넣으세요.
  4. 보상을 받았다면 사용함을 눌러 두세요.

새 코드 알림 받기

  1. 하는 게임의 페이지에서 내 게임에 담기를 누르세요.
  2. 새 쿠폰 알림 받기를 누르고 브라우저 알림을 허용하세요. 아이폰은 먼저 사파리의 공유 버튼에서 홈 화면에 추가를 한 뒤, 홈 화면의 ECM으로 열어야 알림을 켤 수 있어요.
  3. 푸시를 쓰기 어렵다면 텔레그램이나 카카오톡 채널을 구독하세요.

마감일 캘린더로 받기

  1. 오늘의 쿠폰의 캘린더 구독에서 캘린더로 받기를 누르세요(아이폰은 바로 구독돼요).
  2. 구글 캘린더는 주소 복사를 누른 뒤, PC의 구글 캘린더에서 다른 캘린더 추가 → URL로 추가에 붙여 넣으세요.

자주 묻는 질문

코드를 넣었는데 "유효하지 않은 코드"라고 나와요.

먼저 대소문자와 밑줄(_)·하이픈(-)까지 똑같이 넣었는지 확인해 주세요. 복사 버튼을 쓰면 틀릴 일이 없어요. 그래도 안 되면 코드가 이미 끝났을 가능성이 커요. 게임사는 만료를 미리 알리지 않는 경우가 많아서, ECM이 다음 확인 때 목록에서 내려요. 서버·지역을 골라야 하는 게임은 내 캐릭터가 있는 서버를 골랐는지도 확인해 주세요.

회원가입이나 로그인이 필요한가요?

아니요. ECM은 회원가입 없이 쓸 수 있어요. '내 게임'과 '사용함' 표시는 지금 쓰는 기기의 브라우저에만 저장돼요. 다른 기기에서는 따로 담아야 해요.

ECM이 코드를 직접 넣어 보고 올리나요?

모든 코드를 직접 넣어 보지는 않아요. 코드의 근거는 게임사 공식 원문으로 삼고, 공식 원문을 찾은 코드에는 '공식 출처'를 표시해요(아직 찾는 중인 코드는 '참고'). 운영자가 직접 넣어 본 코드에는 '직접 입력해 봤어요'와 날짜가 붙어요. 자세한 기준은 ECM 소개의 확인 기준에 있어요.

만료일이 '미공개'인 코드는 얼마나 쓸 수 있나요?

알 수 없어요. 게임사가 만료일을 알리지 않은 코드라, ECM은 날짜를 짐작해 적지 않아요. ECM 기록을 보면 이런 코드가 며칠 만에 끝나는 경우도 많으니, 보이는 날 바로 넣는 게 안전해요.

새 쿠폰 알림은 어떻게 받나요?

게임 페이지에서 '내 게임에 담기'를 누르고 '새 쿠폰 알림 받기'를 켜면, 그 게임에 새 코드가 올라올 때 웹 푸시로 알려 드려요. 아이폰은 사이트를 홈 화면에 추가한 뒤(iOS 16.4 이상)에만 웹 알림을 받을 수 있어요. 푸시가 어렵다면 텔레그램 채널이나 카카오톡 채널을 구독해 주세요.

캘린더에는 어떤 코드가 들어가나요?

게임사가 만료일을 공지한 코드만 들어가요. 만료일이 공지되지 않은 코드는 날짜가 없어서 캘린더에 넣지 않아요.

찾는 게임이 목록에 없어요.

지금 쓸 수 있는 코드가 없는 게임은 목록에서 잠시 빠져 있다가, 새 코드가 생기면 다시 보여요. 아예 다루지 않는 게임이라면 문의·제보로 알려 주세요.

쿠폰을 놓치지 않는 팁

  • 보이는 날 바로 넣으세요. ECM이 9월 28일부터 10월 15일까지 기록한 새 코드 115개 가운데 만료일이 공지된 코드는 28개뿐이었고, 목록에서 내려간 38개 가운데 28개는 3일 안에 끝났어요. 기록 분석 보기
  • 오류 메시지가 뜨면 문구를 찾아보세요. 넥슨·넷마블·엔씨·카카오게임즈·스토브·호요버스·로블록스 등 게임사별 오류 문구와 해결 방법을 쿠폰 오류 메시지 사전에 공식 안내 기준으로 모아 두었어요.
  • 복사 버튼을 쓰세요. 코드는 대소문자와 밑줄 하나만 달라도 안 들어가요. 손으로 옮겨 적다가 틀리는 경우가 많아요.
  • 조건을 확인하세요. 일부 게임은 일정 레벨을 넘어야 하거나, 서버를 골라야 하거나, 공식 그룹에 가입해야 코드를 넣을 수 있어요. 게임 페이지의 입력하는 곳 안내에 조건을 함께 적어 둬요.
  • 보상은 우편함부터 보세요. 많은 게임이 쿠폰 보상을 바로 주지 않고 게임 안 우편함으로 보내요.
  • 방송·대회 쿠폰은 당일에 끝나는 경우가 많아요. 업데이트 방송이나 대회 중에 나온 코드는 그날 자정 전에 넣는 게 안전해요.
  • 계정 정보를 요구하는 '쿠폰 사이트'는 피하세요. 진짜 쿠폰은 게임 안이나 게임사 공식 페이지에서만 입력해요. 비밀번호를 받는 곳은 사기예요.
