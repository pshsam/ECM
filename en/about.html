About ECM

Every Coupon Matters. ECM collects working game codes and checks each one against official and trusted sources.

ECM started in South Korea in September 2026 at ecm-coupon.com. This English section covers games that are popular in the United States. One person runs the site.

ECM is not related to ECM Vape or any other shop with a similar name. Our only address is ecm-coupon.com.

How we check codes

A wrong code is worse than no code, so we check where every code comes from before it goes on a page.

  • Official channel. When the game's official site, official social account, official Discord or Roblox game page announces a code, one source is enough.
  • Two separate sites. Without an official announcement, two independent sites that cover game codes must both list the code as working in articles dated within the last 14 days.
  • Exact spelling. Those sources must spell the code the same way, capital letters, underscores and dashes included. If they disagree, we follow the official spelling or leave the code out.
  • Not enough on its own. Comments, forum posts and a single site's list are not enough to add a code.

We don't sign in to games or enter codes ourselves. We recheck games on a rolling schedule, and each page shows the date of its last check. When sources mark a code as expired, it moves to that page's expired list. Codes first seen in the last 14 days get a New label.

What we don't do

  • We don't ask you to sign up or sign in.
  • We are not a partner of any game publisher. Game names belong to their owners.
  • We don't post rumored codes.

How the site is paid for

ECM is free to use. The site may show ads, such as Google AdSense, and ads are kept separate from the code lists. Our privacy policy explains the cookies that ads use.
